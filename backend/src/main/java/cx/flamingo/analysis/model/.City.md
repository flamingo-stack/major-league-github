Represents a city entity used for geographic filtering and proximity calculations in the Major League GitHub leaderboard system.

## Key Components

| Field | Type | Description |
|---|---|---|
| `id` | `String` | Unique city identifier |
| `name` | `String` | City display name |
| `stateId` | `String` | Foreign key to associated `State` |
| `population` | `int` | City population |
| `latitude` / `longitude` | `double` | Geographic coordinates for proximity math |
| `regionIds` | `Set<String>` | Associated region identifiers |
| `nearestTeamId` | `String` | Foreign key to the closest MLS `SoccerTeam` |
| `state` | `State` | Resolved `State` reference object |
| `regions` | `Set<Region>` | Resolved `Region` reference objects |
| `nearestTeam` | `SoccerTeam` | Resolved nearest MLS team reference object |

**Annotations:**
- `@Data` / `@Builder` — Lombok-generated getters, setters, and builder pattern
- `@JsonInclude(NON_NULL)` — omits null fields from JSON serialization responses

## Usage Example

```java
City city = City.builder()
    .id("chicago")
    .name("Chicago")
    .stateId("IL")
    .population(2696555)
    .latitude(41.8781)
    .longitude(-87.6298)
    .regionIds(Set.of("midwest"))
    .nearestTeamId("chicago-fire")
    .build();
```

Reference objects (`state`, `regions`, `nearestTeam`) are populated at query time and serialized only when non-null, keeping API responses lean when full hydration is not needed.
