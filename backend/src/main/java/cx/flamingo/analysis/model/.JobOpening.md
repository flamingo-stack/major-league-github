A simple data model representing a job opening, used to surface relevant career opportunities alongside contributor profiles.

## Key Components

| Field | Type | Description |
|-------|------|-------------|
| `id` | `String` | Unique identifier for the job opening |
| `title` | `String` | Job title or role name |
| `location` | `String` | Geographic location of the position |
| `url` | `String` | Link to the full job posting |

Lombok's `@Data` generates getters, setters, `equals`, `hashCode`, and `toString`. `@Builder` provides a fluent builder API for construction.

## Usage Example

```java
JobOpening opening = JobOpening.builder()
    .id("job-123")
    .title("Senior Software Engineer")
    .location("Atlanta, GA")
    .url("https://example.com/jobs/job-123")
    .build();

String title = opening.getTitle();
String location = opening.getLocation();
```
