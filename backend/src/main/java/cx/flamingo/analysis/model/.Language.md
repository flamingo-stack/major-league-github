A simple data model representing a programming language entity used for filtering GitHub contributors in the leaderboard.

## Key Components

| Field | Type | Description |
|---|---|---|
| `id` | `String` | Unique language identifier |
| `name` | `String` | Language name (e.g., `java`, `python`) |
| `displayName` | `String` | Human-readable label shown in the UI |
| `iconUrl` | `String` | URL to the language's icon asset |

**Annotations:**
- `@Data` — generates getters, setters, `equals`, `hashCode`, and `toString`
- `@Builder` — enables the builder pattern for constructing instances
- `@JsonInclude(NON_NULL)` — omits `null` fields from JSON serialization

## Usage Example

```java
Language language = Language.builder()
    .id("java")
    .name("java")
    .displayName("Java")
    .iconUrl("https://cdn.example.com/icons/java.svg")
    .build();
```

Null fields are automatically excluded from API responses, keeping payloads lean when optional properties like `iconUrl` are not set.
