A data model representing a professional soccer team with its associated metadata, geographic coordinates, and stadium information.

## Key Components

| Field | Type | Description |
|---|---|---|
| `id` | `String` | Unique team identifier |
| `name` | `String` | Full team name |
| `city` / `state` | `String` | Geographic location |
| `latitude` / `longitude` | `double` | Coordinates used for proximity filtering to MLS stadiums |
| `league` | `String` | League affiliation (e.g., MLS) |
| `stadium` | `String` | Stadium name |
| `stadiumCapacity` | `int` | Maximum stadium capacity |
| `joinedYear` | `int` | Year the team joined its league |
| `headCoach` | `String` | Current head coach |
| `teamUrl` / `wikipediaUrl` / `logoUrl` | `String` | External resource links |

Lombok annotations (`@Data`, `@Builder`, `@NoArgsConstructor`, `@AllArgsConstructor`) generate boilerplate — getters, setters, builder pattern, and constructors automatically.

## Usage Example

```java
// Builder pattern
SoccerTeam team = SoccerTeam.builder()
    .id("lafc")
    .name("Los Angeles FC")
    .city("Los Angeles")
    .state("CA")
    .latitude(34.0134)
    .longitude(-118.2847)
    .league("MLS")
    .stadium("BMO Stadium")
    .stadiumCapacity(22000)
    .joinedYear(2018)
    .headCoach("Steve Cherundolo")
    .teamUrl("https://www.lafc.com")
    .logoUrl("https://example.com/lafc-logo.png")
    .build();

// Access fields
System.out.println(team.getCity());     // "Los Angeles"
System.out.println(team.getLatitude()); // 34.0134
```
