A generic API response wrapper used across the backend service to return consistent JSON envelopes from REST endpoints.

## Key Components

| Member | Type | Description |
|--------|------|-------------|
| `status` | `String` | Response outcome — `"success"` or `"error"` |
| `message` | `String` | Optional human-readable message |
| `data` | `T` | Generic payload; `null` on error responses |
| `success(T data)` | static factory | Wraps a payload with `"success"` status |
| `success(T data, String message)` | static factory | Same as above, with an optional message |
| `error(String message)` | static factory | Returns an error envelope with no data |

## Usage Example

```java
// Simple success response
ApiResponse<List<PlayerDto>> response = ApiResponse.success(playerList);

// Success with a message
ApiResponse<Void> response = ApiResponse.success(null, "Cache refreshed successfully");

// Error response
ApiResponse<Void> response = ApiResponse.error("GitHub API rate limit exceeded");
```

Serialized JSON shapes:

```json
{ "status": "success", "data": { ... }, "message": null }
{ "status": "error",   "data": null,    "message": "GitHub API rate limit exceeded" }
```

The class is annotated with Lombok `@Data` (generates getters, setters, `equals`, `hashCode`, `toString`) and `@Builder` (enables the fluent builder used internally by the static factories).
