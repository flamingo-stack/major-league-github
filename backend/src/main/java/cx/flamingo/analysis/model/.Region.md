A Lombok `@Value` immutable model representing a geographic region, used to group U.S. states and cities for proximity-based filtering of GitHub contributors near MLS stadiums.

## Key Components

| Member | Type | Description |
|---|---|---|
| `id` | `String` | Unique region identifier |
| `name` | `String` | Internal slug (e.g., `"new-england"`) |
| `displayName` | `String` | Human-readable label (e.g., `"New England"`) |
| `geo` | `GeoCoordinates` | Geographic center of the region |
| `stateIds` | `Set<String>` | Set of state identifier strings belonging to this region |
| `states` | `Set<State>` | Resolved `State` reference objects |
| `cities` | `Set<City>` | Resolved `City` reference objects |
| `GeoCoordinates` | nested `@Value` | Immutable lat/lon pair representing the region's center point |

## Usage Example

```java
Region.GeoCoordinates center = new Region.GeoCoordinates(42.3601, -71.0589);

Region newEngland = new Region(
    "new-england",
    "new-england",
    "New England",
    center,
    Set.of("MA", "CT", "RI", "VT", "NH", "ME"),
    states,
    cities
);

System.out.println(newEngland.getDisplayName()); // "New England"
System.out.println(newEngland.getGeo().getLatitude()); // 42.3601
```

All fields are final and accessible via Lombok-generated getters. No setters are generated — construct a new instance to represent a different region.
