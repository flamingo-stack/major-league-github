A data model representing a hiring manager's public profile, used to surface recruiter and hiring contact information alongside GitHub contributor rankings.

## Key Components

| Field | Type | Description |
|---|---|---|
| `name` | `String` | Display name of the hiring manager |
| `avatarUrl` | `String` | URL to the manager's profile avatar |
| `role` | `String` | Job title or role description |
| `bio` | `String` | Short biographical summary |
| `socialLinks` | `List<SocialLink>` | Collection of social/professional links |
| `githubStats` | `Map<String, Integer>` | Key/value GitHub activity metrics |
| `lastActive` | `Instant` | Timestamp of most recent activity |

Lombok annotations (`@Data`, `@Builder`, `@NoArgsConstructor`, `@AllArgsConstructor`) generate getters, setters, a fluent builder, and both default and all-args constructors.

## Usage Example

```java
HiringManagerProfile profile = HiringManagerProfile.builder()
    .name("Jane Smith")
    .avatarUrl("https://avatars.githubusercontent.com/u/12345")
    .role("Senior Engineering Manager")
    .bio("Building great teams at Acme Corp.")
    .socialLinks(List.of(new SocialLink("linkedin", "https://linkedin.com/in/janesmith")))
    .githubStats(Map.of("repositories", 42, "stars", 310))
    .lastActive(Instant.now())
    .build();
```
