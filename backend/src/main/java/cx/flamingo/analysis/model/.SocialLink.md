A simple data model representing a social media or external platform link associated with a GitHub contributor profile.

## Key Components

| Member | Type | Description |
|--------|------|-------------|
| `platform` | `String` | The name of the platform (e.g., `"Twitter"`, `"LinkedIn"`) |
| `url` | `String` | The full URL to the contributor's profile on that platform |

Lombok annotations provide `@Data` (getters/setters/equals/hashCode/toString), `@Builder` (fluent construction), and both `@NoArgsConstructor`/`@AllArgsConstructor`.

## Usage Example

```java
// Builder pattern
SocialLink twitterLink = SocialLink.builder()
    .platform("Twitter")
    .url("https://twitter.com/octocat")
    .build();

// All-args constructor
SocialLink linkedIn = new SocialLink("LinkedIn", "https://linkedin.com/in/octocat");

// Accessing fields
String platform = twitterLink.getPlatform(); // "Twitter"
String url = twitterLink.getUrl();           // "https://twitter.com/octocat"
```
