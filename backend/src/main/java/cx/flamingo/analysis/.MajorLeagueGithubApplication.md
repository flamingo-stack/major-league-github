Entry point for the Major League GitHub backend service. Bootstraps the Spring Boot application with caching and async processing enabled.

## Key Components

- **`@SpringBootApplication`** – Enables Spring Boot auto-configuration, component scanning, and configuration for the `cx.flamingo.analysis` package.
- **`@EnableCaching`** – Activates Spring's annotation-driven cache management, used with the Redis distributed cache layer.
- **`@EnableAsync`** – Enables Spring's asynchronous method execution, allowing background tasks (such as GitHub data fetching) to run on separate threads.
- **`main(String[] args)`** – Standard Java entry point; delegates to `SpringApplication.run()` to launch the application context.

## Usage Example

```bash
# Run via Maven wrapper
./mvnw spring-boot:run

# Or run the packaged JAR directly
java -jar target/major-league-github.jar
```

```java
// Application starts here — no manual wiring required.
// Spring Boot auto-configures Redis caching and async executors
// based on application properties.
SpringApplication.run(MajorLeagueGithubApplication.class, args);
```

> **Note:** This class belongs to the **Backend Service** (port `8450`). The Cache Updater microservice (port `8451`) has its own application entry point. See the full project at [flamingo-stack/major-league-github](https://github.com/flamingo-stack/major-league-github).
