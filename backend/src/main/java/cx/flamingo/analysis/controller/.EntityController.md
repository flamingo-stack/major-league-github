REST controller that exposes lookup endpoints for core reference entities used in the Major League GitHub leaderboard, including cities, regions, states, programming languages, and MLS soccer teams.

## Key Components

| Endpoint | Method | Description |
|---|---|---|
| `/api/entities/cities/{id}` | `GET` | Fetch a city by ID |
| `/api/entities/regions/{id}` | `GET` | Fetch a region by ID |
| `/api/entities/states/{id}` | `GET` | Fetch a state by ID |
| `/api/entities/languages/{id}` | `GET` | Fetch a programming language by ID |
| `/api/entities/teams/{id}` | `GET` | Fetch an MLS soccer team by ID |

All endpoints return a typed `ApiResponse<T>` wrapper — `ApiResponse.success(...)` on a hit and `ApiResponse.error(...)` with a descriptive message when the entity is not found.

**Injected Services:** `CityService`, `RegionService`, `StateService`, `LanguageService`, `SoccerTeamService`

## Usage Example

```java
// GET /api/entities/cities/nyc
// → 200 OK
{
  "success": true,
  "message": "Found city: New York",
  "data": { "id": "nyc", "name": "New York", ... }
}

// GET /api/entities/teams/unknown-id
// → 200 OK (error envelope)
{
  "success": false,
  "message": "Team not found with ID: unknown-id",
  "data": null
}
```

All not-found cases are logged at `WARN` level via the Lombok `@Slf4j` logger before returning the error response.
