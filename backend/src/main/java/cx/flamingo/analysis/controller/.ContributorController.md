REST controller exposing two endpoints under `/api/contributors` for searching and exporting GitHub contributor leaderboard data as JSON or CSV.

## Key Components

| Member | Type | Description |
|---|---|---|
| `getContributors` | `GET /api/contributors/search` | Returns a ranked list of contributors filtered by location, language, and result count |
| `exportContributors` | `GET /api/contributors/export` | Streams the same filtered results as a downloadable CSV file |
| `githubService` | Dependency | Resolves target cities and fetches ranked contributors from GitHub |
| `cacheService` | Dependency | Gate-checks cache readiness and serves cached HTTP responses |
| `cityService` | Dependency | Looks up city metadata for CSV filename construction |
| `languageService` | Dependency | Resolves the requested or default programming language |

## Shared Query Parameters

Both endpoints accept the same filter parameters:

| Parameter | Default | Description |
|---|---|---|
| `cityId` | — | Filter by a specific city |
| `regionId` | — | Filter by region |
| `stateId` | — | Filter by US state |
| `teamId` | — | Filter by MLS team proximity |
| `languageId` | — | Programming language filter |
| `maxResults` | `15` | Maximum contributors returned |
| `priority` | `High` | GitHub API request priority |

## Usage Example

```java
// Search endpoint — returns JSON ApiResponse
GET /api/contributors/search?languageId=java&cityId=chicago&maxResults=10

// Export endpoint — returns a CSV file download
// Filename format: mlg-contributors-{language}-{location}-{date}.csv
GET /api/contributors/export?languageId=java&stateId=IL&maxResults=25

// CSV columns produced:
// Rank, First Name, Last Name, City, State, MLG URL, GitHub URL, Email, Twitter, LinkedIn
```

Cache readiness is checked before processing either request. If the cache is not yet populated, `search` returns an `ApiResponse.error(...)` and `export` returns HTTP 400. On success, `export` sets `Content-Disposition: attachment` with a descriptive filename such as `mlg-contributors-java-IL-2025-01-15.csv`.
