REST controller that exposes hiring-related API endpoints, returning hiring manager profile data and available job openings.

## Key Components

| Component | Description |
|---|---|
| `HiringController` | `@RestController` mapped to `/api/hiring` |
| `GET /api/hiring/manager` | Returns hiring manager profile from `HiringService` |
| `GET /api/hiring/jobs` | Returns a wrapped list of `JobOpening` objects with status metadata |
| `HiringService` | Injected dependency that provides the underlying hiring data |

## Usage Example

```java
// GET /api/hiring/manager
// Returns hiring manager profile map directly from HiringService

// GET /api/hiring/jobs
// Returns a structured response:
{
  "status": "success",
  "message": "Job openings retrieved successfully",
  "data": [ /* List<JobOpening> */ ]
}
```

```java
// Wiring via Spring (automatic with @RequiredArgsConstructor)
@Service
public class HiringService {
    public Map<String, Object> getHiringManagerProfile() { ... }
    public List<JobOpening> getJobOpenings() { ... }
}
```

## Notes

- `/api/hiring/jobs` wraps its response in a consistent envelope (`status`, `message`, `data`), while `/api/hiring/manager` returns the raw map from `HiringService` directly — consider aligning these response shapes for consistency.
- No authentication or caching annotations are present; if these endpoints are publicly exposed they should be reviewed alongside the project's Spring Security configuration.
