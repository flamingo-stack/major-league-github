Unchecked exception thrown when a GitHub API request exceeds its configured timeout threshold.

## Key Components

| Constructor | Description |
|---|---|
| `GithubTimeoutException(String message)` | Creates exception with a descriptive timeout message |
| `GithubTimeoutException(String message, Throwable cause)` | Creates exception wrapping an underlying cause (e.g., `SocketTimeoutException`) |

## Usage Example

```java
try {
    githubClient.fetchContributors(language, location);
} catch (SocketTimeoutException e) {
    throw new GithubTimeoutException(
        "GitHub API timed out fetching contributors for: " + location, e
    );
}
```

Catch this exception at the service layer to return a graceful HTTP 504 response or trigger a cache fallback instead of surfacing raw timeout errors to the client.
