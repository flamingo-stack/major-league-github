Global Spring `@ControllerAdvice` that intercepts all unhandled exceptions across the Backend Service and returns a structured JSON error response.

## Key Components

- **`@ControllerAdvice`** — Applies exception handling globally to all controllers in the application.
- **`handleAllExceptions(Exception, WebRequest)`** — Catches any `Exception` not handled elsewhere, logs it at ERROR level, and wraps it in an `ApiError` response body with HTTP 500.
- **`ApiError`** — Builder-constructed payload containing `timestamp`, `status`, `error`, `message`, and `path` fields.

## Usage Example

Any unhandled exception thrown from a controller or service automatically produces a consistent error envelope:

```java
// Any controller that throws an unexpected exception:
@GetMapping("/contributors")
public List<Contributor> getContributors() {
    throw new RuntimeException("Database unavailable");
}

// Automatically intercepted → HTTP 500 response body:
// {
//   "timestamp": "2025-01-15T10:30:00",
//   "status": 500,
//   "error": "Internal Server Error",
//   "message": "Database unavailable",
//   "path": "uri=/contributors"
// }
```

No additional configuration is required. Because the handler targets the base `Exception` class, it acts as a catch-all safety net; more specific handlers (if added later) take precedence due to Spring MVC's exception resolver ordering.
