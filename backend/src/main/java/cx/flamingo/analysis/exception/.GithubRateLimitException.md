A custom unchecked exception thrown when the GitHub API rate limit has been exceeded.

## Key Components

- **`GithubRateLimitException(String message)`** — constructs the exception with a descriptive message
- **`GithubRateLimitException(String message, Throwable cause)`** — constructs the exception with a message and an underlying cause for exception chaining

## Usage Example

```java
// Throw when a GitHub API response indicates rate limit exhaustion
if (response.getStatusCode() == HttpStatus.FORBIDDEN) {
    throw new GithubRateLimitException("GitHub API rate limit exceeded. Retry after reset.");
}

// With cause chaining
try {
    githubClient.fetchUser(username);
} catch (WebClientResponseException.Forbidden e) {
    throw new GithubRateLimitException("Rate limit hit fetching user: " + username, e);
}
```

Callers can catch this exception specifically to apply retry logic or surface a meaningful error response, distinct from other runtime failures.

```java
try {
    contributorService.refresh();
} catch (GithubRateLimitException e) {
    log.warn("Skipping refresh: {}", e.getMessage());
    // Schedule retry after rate limit window resets
}
```
