A simple data transfer object representing a structured error response payload returned by the API when exceptions occur.

## Key Components

| Field | Type | Description |
|-------|------|-------------|
| `timestamp` | `LocalDateTime` | When the error occurred |
| `status` | `int` | HTTP status code |
| `error` | `String` | Short error category (e.g. `"Not Found"`) |
| `message` | `String` | Human-readable error detail |
| `path` | `String` | Request path that triggered the error |

## Usage Example

```java
ApiError apiError = ApiError.builder()
    .timestamp(LocalDateTime.now())
    .status(HttpStatus.NOT_FOUND.value())
    .error(HttpStatus.NOT_FOUND.getReasonPhrase())
    .message("Contributor not found for the given username")
    .path("/api/contributors/unknown-user")
    .build();
```

Lombok's `@Data` and `@Builder` annotations generate getters, setters, `equals`/`hashCode`, and the fluent builder pattern automatically, keeping the class boilerplate-free.
