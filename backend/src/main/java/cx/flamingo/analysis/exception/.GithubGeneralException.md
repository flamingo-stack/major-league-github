A general-purpose unchecked exception for signaling GitHub API-related errors within the analysis service.

## Key Components

- **`GithubGeneralException(String message)`** — constructs the exception with a descriptive error message.
- **`GithubGeneralException(String message, Throwable cause)`** — constructs the exception wrapping an underlying cause, useful for preserving the original stack trace when re-throwing.

## Usage Example

```java
// Throw with a message only
throw new GithubGeneralException("GitHub API rate limit exceeded");

// Wrap an underlying cause
try {
    githubClient.fetchUser(username);
} catch (IOException e) {
    throw new GithubGeneralException("Failed to fetch GitHub user: " + username, e);
}
```
