A runtime exception thrown when GitHub API rate limits are hit or requests are being made too rapidly, signaling that the application should back off before retrying.

## Key Components

| Component | Description |
|---|---|
| `GithubTooFastException(String message)` | Constructs the exception with a descriptive message |
| `GithubTooFastException(String message, Throwable cause)` | Constructs the exception with a message and the underlying cause |

## Usage Example

```java
// Throw when a 429 or secondary rate limit response is detected
if (response.getStatusCode() == 429) {
    throw new GithubTooFastException("GitHub rate limit exceeded: " + response.getBody());
}

// Wrap an underlying HTTP exception
try {
    githubClient.fetchUser(username);
} catch (HttpClientErrorException ex) {
    throw new GithubTooFastException("Too many GitHub requests", ex);
}
```

## Notes

- Extends `RuntimeException`, so callers are not required to declare or catch it explicitly.
- Intended to be caught at a higher level (e.g., a retry handler or scheduler) to pause execution and respect GitHub's rate limiting policies.
