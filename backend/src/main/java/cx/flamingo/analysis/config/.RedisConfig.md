Configures Redis connectivity and JSON serialization beans for the application, including a Lettuce-backed connection factory, a `RedisTemplate` with string serializers, and a Gson instance with custom `Instant` and `LocalDateTime` adapters.

## Key Components

| Bean / Class | Description |
|---|---|
| `redisConnectionFactory()` | Creates a `LettuceConnectionFactory` pointed at the host and port from `spring.redis.host` / `spring.redis.port` (defaults: `localhost:6379`) |
| `redisTemplate()` | Configures a `RedisTemplate<String, Object>` using `StringRedisSerializer` for all keys and values; transaction support enabled |
| `gson()` | Produces a `Gson` instance registered with adapters for `Instant` (ISO-8601 string) and `LocalDateTime` |
| `InstantTypeAdapter` | Private `TypeAdapter` that serializes `Instant` to/from its ISO-8601 string representation; handles `null` safely |

## Usage Example

```java
// Inject RedisTemplate to store/retrieve a cached value
@Service
public class LeaderboardCacheService {

    private final RedisTemplate<String, Object> redisTemplate;
    private final Gson gson;

    public LeaderboardCacheService(RedisTemplate<String, Object> redisTemplate, Gson gson) {
        this.redisTemplate = redisTemplate;
        this.gson = gson;
    }

    public void cacheLeaderboard(String key, LeaderboardEntry entry) {
        redisTemplate.opsForValue().set(key, gson.toJson(entry));
    }

    public LeaderboardEntry getLeaderboard(String key) {
        String json = (String) redisTemplate.opsForValue().get(key);
        return gson.fromJson(json, LeaderboardEntry.class);
    }
}
```

## Configuration Properties

```yaml
spring:
  redis:
    host: localhost   # default
    port: 6379        # default
```

> **Note:** `LocalDateTimeAdapter` is registered with the `Gson` bean but is not defined in this file — it is expected to be provided elsewhere in the `cx.flamingo.analysis.config` package.
