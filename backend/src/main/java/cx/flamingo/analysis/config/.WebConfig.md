Configures Cross-Origin Resource Sharing (CORS) for the Spring MVC backend, permitting requests from both local development servers and the production `mlg.soccer` domain.

## Key Components

| Element | Description |
|---|---|
| `WebConfig` | `@Configuration` class implementing `WebMvcConfigurer` |
| `addCorsMappings` | Registers CORS rules for all endpoints (`/**`), including Spring Actuator |
| `activeProfile` | Injects the active Spring profile via `${spring.profiles.active}` (unused directly but available for future profile-conditional logic) |

**Allowed origins:**

| Origin | Environment |
|---|---|
| `http://localhost:8450` | Backend local dev |
| `http://localhost:3000` | Frontend local dev |
| `https://www.mlg.soccer` | Production (HTTPS) |
| `http://www.mlg.soccer` | Ingress controller |

**CORS policy summary:**
- Methods: `GET`, `POST`, `PUT`, `DELETE`, `OPTIONS`
- Headers: all (`*`)
- Credentials: allowed
- Preflight cache: 3600 seconds (1 hour)

## Usage Example

This class is auto-detected by Spring Boot via `@Configuration` — no manual registration needed. CORS rules apply globally across all controllers and actuator endpoints.

```java
// No manual wiring required. Spring Boot picks this up automatically.
// To add a new allowed origin, append to the allowedOrigins() list:

registry.addMapping("/**")
    .allowedOrigins(
        "http://localhost:3000",
        "https://www.mlg.soccer",
        "https://staging.mlg.soccer" // new staging origin
    );
```
