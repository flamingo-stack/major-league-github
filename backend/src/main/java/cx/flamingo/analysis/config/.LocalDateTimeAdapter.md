A Gson type adapter that handles serialization and deserialization of `LocalDateTime` objects using the ISO 8601 local date-time format (e.g., `2024-06-15T14:30:00`).

## Key Components

- **`LocalDateTimeAdapter`** — Implements both `JsonSerializer<LocalDateTime>` and `JsonDeserializer<LocalDateTime>` for Gson.
- **`formatter`** — Static `DateTimeFormatter.ISO_LOCAL_DATE_TIME` instance used for consistent formatting across serialize/deserialize operations.
- **`serialize()`** — Converts a `LocalDateTime` to a `JsonPrimitive` string.
- **`deserialize()`** — Parses a JSON string back into a `LocalDateTime`, throwing `JsonParseException` on invalid input.

## Usage Example

Register the adapter with a `GsonBuilder` before building your `Gson` instance:

```java
Gson gson = new GsonBuilder()
    .registerTypeAdapter(LocalDateTime.class, new LocalDateTimeAdapter())
    .create();

// Serialize
LocalDateTime now = LocalDateTime.now();
String json = gson.toJson(now);
// → "2024-06-15T14:30:00"

// Deserialize
LocalDateTime parsed = gson.fromJson("\"2024-06-15T14:30:00\"", LocalDateTime.class);
```

> **Note:** `LocalDateTime` has no timezone information. If timezone awareness is needed, consider using `ZonedDateTime` or `OffsetDateTime` with a corresponding adapter instead.
