Marks the Spring application context as a Web MVC configuration, activated exclusively when the `backend-service` profile is active.

## Key Components

| Element | Description |
|---|---|
| `@Configuration` | Declares this as a Spring configuration class |
| `@Profile("backend-service")` | Restricts loading to the `backend-service` Spring profile |
| `@EnableWebMvc` | Enables full Spring MVC support for the Backend Service microservice |

## Usage Example

This class is activated automatically when the `backend-service` Spring profile is set — no manual instantiation required.

```bash
# Run with the backend-service profile (port 8450)
java -jar app.jar --spring.profiles.active=backend-service
```

```java
// Or activate programmatically in tests
@SpringBootTest
@ActiveProfiles("backend-service")
class BackendServiceConfigTest {
    // context loads with Web MVC enabled
}
```

> **Note:** The `cache-updater` profile (port 8451) intentionally omits this class, keeping the two microservices' MVC configurations isolated from one another.
