Spring Boot configuration class that activates scheduling support exclusively for the `cache-updater` profile, enabling the Cache Updater microservice to run its background data refresh jobs.

## Key Components

| Element | Description |
|---|---|
| `@Profile("cache-updater")` | Restricts this configuration to the `cache-updater` Spring profile (port 8451) |
| `@EnableScheduling` | Activates Spring's task scheduling, required for periodic GitHub data refresh |
| `WebMvcAutoConfiguration` | Extends base MVC auto-configuration for the service |

## Usage Example

This configuration is activated automatically when the `cache-updater` Spring profile is set. No manual instantiation is required.

```bash
# Activate the cache-updater profile via environment variable
SPRING_PROFILES_ACTIVE=cache-updater java -jar app.jar
```

```java
// Scheduled tasks in other beans are enabled by this config
@Component
@Profile("cache-updater")
public class GitHubCacheRefresher {

    @Scheduled(fixedRateString = "${cache.refresh.rate}")
    public void refreshCache() {
        // Runs only when cache-updater profile is active
    }
}
```

> **Note:** This class is intentionally minimal. The `cache-updater` profile separates scheduling concerns from the Backend Service (port 8450), ensuring that only one microservice drives cache updates while the other focuses on serving API requests.
