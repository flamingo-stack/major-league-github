Fetches and caches job postings from the LinkedIn API for a configured organization, using OAuth2 client credentials for authentication.

## Key Components

| Component | Description |
|---|---|
| `getCompanyJobPostings()` | Retrieves job postings for the configured organization, returning cached results when available |
| `extractLocation()` | Parses location data from a LinkedIn job JSON object, falling back to `"Remote"` if unavailable |
| `LinkedInJobPosting` | Inner record representing the raw LinkedIn API job posting shape |

**Configuration properties (injected via `@Value`):**

| Property | Description |
|---|---|
| `linkedin.client.id` | LinkedIn OAuth2 client ID |
| `linkedin.client.secret` | LinkedIn OAuth2 client secret |
| `linkedin.organization.id` | Target organization ID for job listing queries |
| `linkedin.cache.refresh.interval` | Cache TTL in milliseconds (default: `3600000` / 1 hour) |

## Usage Example

```java
@RestController
@RequiredArgsConstructor
public class JobsController {

    private final LinkedInService linkedInService;

    @GetMapping("/api/jobs")
    public List<JobOpening> getJobs() {
        // Returns cached results when available; fetches from LinkedIn API otherwise
        return linkedInService.getCompanyJobPostings();
    }
}
```

**Cache behavior:** Results are stored under the `linkedin/jobs_{organizationId}` cache key via `CacheServiceAbs`. On cache miss, the service performs two HTTP calls — a `POST` to the LinkedIn token endpoint to obtain an access token via client credentials, followed by a `GET` to the organization updates endpoint — then filters the response for entries containing a `jobPosting` content block before caching and returning the result. Errors are logged and an empty list is returned as a fallback.
