Loads and manages MLS soccer team data from a bundled CSV file, providing lookup, proximity search, and autocomplete capabilities for use throughout the backend service.

## Key Components

| Method | Description |
|---|---|
| `init()` / `loadTeams()` | `@PostConstruct` startup routine that parses `data/teams.csv` from the classpath into a list of `SoccerTeam` objects |
| `findNearestTeamId(City)` | Returns the ID of the MLS team whose stadium is geographically closest to the given city using the Haversine formula |
| `getTeamById(String)` | Looks up a single `SoccerTeam` by its string ID |
| `getAllTeams()` | Returns the full in-memory list of all loaded teams |
| `autocompleteTeams(String, int)` | Searches teams by name, city, or state (case-insensitive); falls back to stadium-capacity ordering when the query is blank |
| `calculateDistance(...)` | Private Haversine implementation computing great-circle distance in kilometers between two lat/lon coordinates |

## Usage Example

```java
// Inject the service
@Autowired
private SoccerTeamService soccerTeamService;

// Find the nearest MLS team to a city
City userCity = City.builder()
    .latitude(40.7128)
    .longitude(-74.0060)
    .build();
String nearestId = soccerTeamService.findNearestTeamId(userCity);
SoccerTeam team = soccerTeamService.getTeamById(nearestId);
// → e.g., SoccerTeam(name="New York Red Bulls", stadium="Red Bull Arena", ...)

// Autocomplete search (top 5 results by stadium capacity)
List<SoccerTeam> suggestions = soccerTeamService.autocompleteTeams("los", 5);
```

> **Data source:** `src/main/resources/data/teams.csv` — a comma-separated file with 14 columns (id, name, city, state, latitude, longitude, league, stadium, stadiumCapacity, joinedYear, headCoach, teamUrl, wikipediaUrl, logoUrl). The entire dataset is loaded once at startup and held in memory.
