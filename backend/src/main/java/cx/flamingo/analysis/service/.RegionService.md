Manages the in-memory collection of geographic regions loaded from a CSV file at startup, providing lookup, filtering, and autocomplete capabilities used throughout the Major League GitHub backend.

## Key Components

| Method | Description |
|---|---|
| `init()` / `loadRegions()` | `@PostConstruct` initializer that reads `data/regions.csv` from the classpath, parsing id, name, display name, coordinates, and associated state IDs into `Region` objects |
| `autocompleteRegions(query, stateId, cityIds, maxResults)` | Filters regions by state, associated city IDs, and name query, then returns results sorted by total population descending |
| `updateRegion(updatedRegion)` | Replaces an existing region in the in-memory list by ID; logs a warning if the region is not found |
| `getRegionById(id)` | Returns a single `Region` by exact ID match, or `null` if not found |
| `getRegionByName(name)` | Returns a single `Region` by case-insensitive name match, or `null` if not found |
| `getAllRegions()` | Returns a defensive copy of the full regions list |
| `getRegionTotalPopulation(region)` | Private helper that sums populations of all cities associated with a given region via `CityService` |

## Usage Example

```java
// Autocomplete regions by name query, filtered to a specific state
List<Region> results = regionService.autocompleteRegions("pacific", "CA", null, 5);

// Look up a region directly by ID
Region region = regionService.getRegionById("west-coast");

// Update a region after enriching it with additional data
Region updated = new Region("west-coast", "West Coast", "West Coast US",
    new Region.GeoCoordinates(37.7, -122.4),
    Set.of("CA", "OR", "WA"),
    Set.of(),
    Set.of()
);
regionService.updateRegion(updated);
```

## Notes

- Regions are loaded once at startup from `src/main/resources/data/regions.csv`. A pipe (`|`) delimiter separates multiple state IDs within a single CSV field.
- Population-based sorting in `autocompleteRegions` is computed dynamically via `CityService` on each call; results are not cached at the region level.
