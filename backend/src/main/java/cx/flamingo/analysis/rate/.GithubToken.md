A data model representing a GitHub API token along with its rate limit state, used to track both primary and secondary rate limit conditions across the Major League GitHub backend services.

## Key Components

| Member | Type | Description |
|---|---|---|
| `token` | `String` | The raw GitHub API token value |
| `remainingRequests` | `Integer` | Maps to `X-RateLimit-Remaining` response header |
| `resetTime` | `Long` | Unix timestamp from `X-RateLimit-Reset` header |
| `rateLimit` | `Integer` | Maps to `X-RateLimit-Limit` response header |
| `usedRequests` | `Integer` | Maps to `X-RateLimit-Used` response header |
| `retryAfterSeconds` | `Integer` | Wait duration from `Retry-After` header on secondary limit hits |
| `lastSecondaryLimitHit` | `Long` | Millisecond timestamp of the most recent secondary limit encounter |
| `isUnderSecondaryLimit()` | `boolean` | Returns `true` if the `Retry-After` window has not yet elapsed |
| `hasRemainingRequests()` | `boolean` | Returns `true` if requests remain and no secondary limit is active |
| `getSecondsUntilReset()` | `long` | Returns seconds until the primary rate limit window resets |

## Usage Example

```java
GithubToken token = GithubToken.builder()
    .token("ghp_exampleToken123")
    .remainingRequests(42)
    .rateLimit(5000)
    .usedRequests(4958)
    .resetTime(Instant.now().getEpochSecond() + 300)
    .build();

if (token.hasRemainingRequests()) {
    // Safe to make a GitHub API call
    long waitSeconds = token.getSecondsUntilReset();
} else if (token.isUnderSecondaryLimit()) {
    // Back off; secondary limit is active
}
```

> **Note:** `@JsonInclude(NON_NULL)` ensures unpopulated rate limit fields are omitted from serialized responses, keeping payloads clean when secondary limit data is absent.
