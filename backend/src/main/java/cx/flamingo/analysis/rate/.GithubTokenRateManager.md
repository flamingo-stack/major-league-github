Manages a pool of GitHub API tokens, tracking rate limits for each and selecting the optimal token for outgoing requests.

## Key Components

- **`tokenMap`** — Internal `HashMap` keyed by token string, storing each token's `GithubToken` metadata and its dedicated `WebClient` as a `Pair`.
- **`initializeRateLimits()`** — Calls GitHub's rate-limit endpoint for every token once (guarded by `alreadyInitialized`), populates rate-limit metadata, and logs a status summary.
- **`getBestAvailableClient()`** — Returns the `WebClient`/`GithubToken` pair with the most remaining calls. Automatically blocks and waits when all tokens are under a secondary rate limit or fully exhausted, then retries.
- **`updateTokenRateLimits(GithubToken, Map<String, List<String>>)`** — Parses `X-RateLimit-Remaining`, `X-RateLimit-Reset`, `X-RateLimit-Limit`, `X-RateLimit-Used`, and `Retry-After` response headers to update a token's state.
- **`init()`** (`@PostConstruct`) — Builds a `WebClient` per token with a 1 MB in-memory buffer and registers them in `tokenMap`.

## Usage Example

```java
@Service
public class GithubSearchService {

    private final GithubTokenRateManager rateManager;

    public GithubSearchService(GithubTokenRateManager rateManager) {
        this.rateManager = rateManager;
    }

    public String fetchUser(String username) {
        // Retrieve the token with the most remaining API calls
        Pair<WebClient, GithubToken> best = rateManager.getBestAvailableClient();
        WebClient client   = best.getValue0();
        GithubToken token  = best.getValue1();

        String body = client.get()
                .uri("/users/{user}", username)
                .retrieve()
                .bodyToMono(String.class)
                .block();

        // Refresh rate-limit counters from the response headers
        // (headers sourced from the actual WebClient response)
        rateManager.updateTokenRateLimits(token, responseHeaders);
        return body;
    }
}
```

> **Configuration required** — the following properties must be set in `application.yml` (or equivalent):
> - `github.tokens` — comma-separated list of Personal Access Tokens
> - `github.api.url` — GitHub REST API base URL
> - `github.api.url.rate_limit` — full URL to GitHub's `/rate_limit` endpoint
