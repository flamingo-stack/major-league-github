Represents a single node in a GraphQL query tree, holding a field name, arguments, and nested subfields with a fluent builder API for constructing queries programmatically.

## Key Components

| Member | Type | Description |
|--------|------|-------------|
| `name` | `String` | The GraphQL field name |
| `args` | `Map<String, Object>` | Key-value arguments for the field |
| `subfields` | `List<Field>` | Nested child fields |
| `parent` | `Field` | Reference to the parent field for traversal |
| `addArg(key, value)` | `Field` | Appends an argument and returns `this` for chaining |
| `addField(name)` | `Field` | Creates and registers a child field, returns the **child** |
| `addField(field)` | `Field` | Attaches an existing `Field` as a child, returns the **child** |
| `add(name)` | `Field` | Adds a sibling field and returns the **parent** (for breadth-first building) |
| `nest(name)` | `Field` | Adds a child field and returns the **child** (for depth-first building) |

## Usage Example

```java
// Build: user(id: "42") { login repos { name language } }
Field user = new Field("user")
    .addArg("id", "42");

user.nest("login")
    .add("repos")          // adds sibling, returns parent
    .nest("repos");        // not needed — shown for clarity

// Alternatively, use add() to stay at the same level
Field root = new Field("user").addArg("id", "42");
root.nest("login");
Field repos = root.nest("repos");
repos.nest("name").add("language");
```

> **Traversal note:** `add()` returns the parent so callers can chain sibling fields horizontally, while `nest()` descends into a new child field — mirroring how `GraphQLQueryBuilder` walks the tree during query serialization.
