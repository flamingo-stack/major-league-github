Builds GitHub GraphQL search queries using a fluent builder API, producing valid `query { search(...) { ... } }` strings for fetching ranked user data.

## Key Components

- **`GitHubQueryBuilder`** — Top-level builder; entry point for constructing a complete GraphQL query string via `build()`
- **`searchUsers(int size)`** — Configures the search for `USER` type and applies default sorts (`repositories`, `stars`, `followers` descending)
- **`location(String)`** / **`language(String)`** / **`cursor(String)`** — Chainable filter methods for geographic location, programming language, and pagination cursor
- **`Field`** (static inner class) — General-purpose GraphQL field node supporting aliases, arguments, and recursive subfield composition via `addField()` and `build()`
- **`SearchField`** (static inner class extending `Field`) — Specialized field for `search`; pre-populates default user subfields including profile data, contribution calendar, social accounts, and top repositories on construction

## Usage Example

```java
GitHubQueryBuilder builder = new GitHubQueryBuilder();

String query = builder
    .searchUsers(25)
    .location("Austin")
    .language("Java")
    .cursor("Y3Vyc29yOjE=")
    .build();

// Produces:
// query { search(type: USER, first: 25, query: "location:\"Austin\" language:Java ... sort:...", after: "Y3Vyc29yOjE=") { userCount pageInfo { ... } nodes { ... on User { login name ... } } } }
```

The resulting query string is sent directly to the GitHub GraphQL API (`api.github.com/graphql`) by the backend service to retrieve paginated, filtered contributor data.
