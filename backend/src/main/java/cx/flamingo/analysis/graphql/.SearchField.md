A specialized `Field` subclass for building GitHub GraphQL search queries by incrementally appending query parts into a single `query` argument string.

## Key Components

- **`SearchField(String name)`** — Constructor that initializes the field with a given GraphQL field name.
- **`appendQuery(String queryPart)`** — Appends a search qualifier to the internal query string, space-delimited, and updates the `query` argument automatically. Returns `this` for chaining.
- **`addArg(String key, Object value)`** — Overrides `Field.addArg` to return `SearchField` for fluent chaining.

## Usage Example

```java
SearchField search = new SearchField("search")
    .appendQuery("language:Java")
    .appendQuery("location:Seattle")
    .addArg("type", "USER")
    .addArg("first", 10);

// Produces a GraphQL field with: query: "language:Java location:Seattle"
```

Internally, each call to `appendQuery` joins tokens with a space and wraps the result in quotes before storing it as the `query` arg, matching the format expected by the GitHub GraphQL Search API.
