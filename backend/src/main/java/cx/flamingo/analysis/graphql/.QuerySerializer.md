Converts a structured list of `Field` objects into a formatted GraphQL query string, handling nested subfields and arguments with proper indentation.

## Key Components

- **`serialize(List<Field> fields)`** — Public entry point; returns the complete GraphQL query string from a list of top-level fields.
- **`serializeFields(...)`** — Wraps fields in a `query { }` root block and manages top-level indentation.
- **`serializeField(...)`** — Recursively serializes a single field, including inline fragment syntax (`... on`), nested subfields, and closing braces.
- **`serializeArguments(...)`** — Renders a field's argument map as a parenthesized, comma-separated argument list (e.g., `(login: "octocat", first: 10)`).
- **`appendIndent(...)`** — Applies the current indentation level using repeated spaces (increments of 2).

## Usage Example

```java
Field loginArg = new Field("user", Map.of("login: \"octocat\"", ""), List.of(
    new Field("name", Map.of(), List.of()),
    new Field("email", Map.of(), List.of())
));

QuerySerializer serializer = new QuerySerializer();
String query = serializer.serialize(List.of(loginArg));
// Output:
// query {
//   user(login: "octocat") {
//     name
//     email
//   }
// }
```

## Notes

- Indentation is stateful — `QuerySerializer` instances should not be reused across multiple `serialize()` calls, as `indent` is not reset between invocations.
- Argument values are serialized via `toString()` regardless of type; callers are responsible for pre-formatting values (e.g., quoting strings) before passing them in `args`.
