Enum representing the categories of GitHub search queries supported by the GraphQL client layer.

## Key Components

| Constant | Description |
|---|---|
| `USER` | Search GitHub user profiles |
| `REPOSITORY` | Search GitHub repositories |
| `ISSUE` | Search GitHub issues |
| `DISCUSSION` | Search GitHub discussions |
| `CODE` | Search GitHub code |

`toString()` returns the enum constant's name verbatim (e.g., `"USER"`, `"CODE"`), making it safe to embed directly in GraphQL query strings.

## Usage Example

```java
SearchType type = SearchType.USER;
String queryType = type.toString(); // "USER"

// Typical use in a GraphQL search query builder
String query = String.format("search(query: \"%s\", type: %s, first: 10)",
    searchTerm,
    SearchType.REPOSITORY
);
```
