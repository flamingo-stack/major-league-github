Vite and SVGR type declarations for the React frontend, enabling TypeScript to resolve `.svg` imports as both URL strings and React components.

## Key Components

- **`vite/client` reference** — Injects Vite's built-in client types (e.g., `import.meta.env`, `import.meta.hot`)
- **`vite-plugin-svgr/client` reference** — Adds SVGR plugin types for SVG-as-component support
- **`*.svg` module declaration** — Extends TypeScript's module resolution for SVG files with two export shapes:
  - `ReactComponent` — A typed `React.FunctionComponent` accepting standard `SVGProps` plus an optional `title` prop
  - `default` (`src`) — The raw SVG file URL as a `string`

## Usage Example

```typescript
// Import as a React component (named export)
import { ReactComponent as Logo } from './assets/logo.svg';

// Import as a URL string (default export)
import logoUrl from './assets/logo.svg';

// Using the component
const Header = () => (
  <>
    <Logo title="Site Logo" width={48} height={48} />
    <img src={logoUrl} alt="Site Logo" />
  </>
);
```

## Notes

- The dual-export pattern mirrors the behavior configured by `vite-plugin-svgr` — both forms can coexist in the same import statement using named + default imports.
- This file lives at [`frontend/src/vite-env.d.ts`](https://github.com/flamingo-stack/major-league-github/blob/main/frontend/src/vite-env.d.ts) and is automatically picked up by TypeScript via `tsconfig.json`'s `include` glob.
