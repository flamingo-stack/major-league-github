Utility module providing two date formatting functions for converting Unix timestamps into human-readable strings.

## Key Components

- **`formatDate(timestamp)`** — Converts a Unix timestamp (seconds) to a localized date string in `en-US` format (e.g., `Jan 5, 2025`).
- **`formatDateRelative(timestamp)`** — Converts a Unix timestamp to a relative time string (e.g., `3 hours ago`, `just now`), with thresholds for minutes, hours, days, months, and years.

## Usage Example

```typescript
import { formatDate, formatDateRelative } from './date';

const timestamp = 1736100000; // Unix seconds

formatDate(timestamp);
// → "Jan 5, 2025"

formatDateRelative(timestamp);
// → "3 days ago"  (depending on when called)
```

## Relative Time Thresholds

| Range | Output |
|---|---|
| < 60 seconds | `just now` |
| < 60 minutes | `N minute(s) ago` |
| < 24 hours | `N hour(s) ago` |
| < 30 days | `N day(s) ago` |
| < 365 days | `N month(s) ago` |
| 365+ days | `N year(s) ago` |

> **Note:** Both functions expect timestamps in **Unix seconds**, not milliseconds. Internally, values are multiplied by `1000` before being passed to `new Date()`.
