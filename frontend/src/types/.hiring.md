Defines TypeScript interfaces for the hiring feature, modeling social link profiles, job openings, and hiring manager data including GitHub activity statistics.

## Key Components

| Export | Type | Description |
|--------|------|-------------|
| `SocialLink` | Interface | A platform identifier and URL pair for a supported social/contact channel |
| `JobOpening` | Interface | A job listing with ID, title, location, and application URL |
| `HiringManagerProfile` | Interface | Full profile for a hiring manager, including bio, social links, and GitHub stats |

**Supported `SocialLink` platforms:** `linkedin`, `twitter`, `x`, `github`, `facebook`, `instagram`, `mastodon`, `bluesky`, `email`, `website`

**`HiringManagerProfile.githubStats` fields:**

| Field | Type | Description |
|-------|------|-------------|
| `score` | `number` | MLG ranking score |
| `totalCommits` | `number` | Lifetime commit count |
| `starsGiven` / `starsReceived` | `number` | Star activity |
| `forksGiven` / `forksReceived` | `number` | Fork activity |
| `javaRepos` | `number` | Java repository count |
| `totalPullRequests` | `number` | Total PRs opened |
| `totalIssues` | `number` | Total issues opened |

## Usage Example

```typescript
import { HiringManagerProfile, JobOpening, SocialLink } from './hiring';

const socialLinks: SocialLink[] = [
  { platform: 'github', url: 'https://github.com/octocat' },
  { platform: 'linkedin', url: 'https://linkedin.com/in/octocat' },
];

const profile: HiringManagerProfile = {
  name: 'Mona Octocat',
  avatarUrl: 'https://avatars.githubusercontent.com/u/583231',
  role: 'Senior Engineer',
  bio: 'Open source enthusiast and GitHub mascot.',
  socialLinks,
  githubStats: {
    score: 9800,
    totalCommits: 4200,
    starsGiven: 310,
    starsReceived: 1050,
    forksReceived: 88,
    forksGiven: 42,
    javaRepos: 3,
    totalPullRequests: 215,
    totalIssues: 97,
  },
  lastActive: Date.now(),
};

const opening: JobOpening = {
  id: 'eng-001',
  title: 'Staff Software Engineer',
  location: 'Remote – USA',
  url: 'https://example.com/jobs/eng-001',
};
```
