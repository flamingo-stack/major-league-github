TypeScript module declaration that allows importing SVG files in a React project, providing both a React component and a raw URL string export.

## Key Components

| Export | Type | Description |
|---|---|---|
| `ReactComponent` | `ForwardRefExoticComponent` | SVG rendered as a React component with full SVG prop support and ref forwarding |
| `default` (`src`) | `string` | The resolved URL of the SVG asset (e.g., for use in `<img src>`) |

## Usage Example

```typescript
// Import as a React component
import { ReactComponent as Logo } from './logo.svg';

// Import as a URL string
import logoUrl from './logo.svg';

// Render as a React component (supports SVG props and refs)
const App = () => (
  <>
    <Logo width={48} height={48} aria-label="Logo" />
    <img src={logoUrl} alt="Logo" />
  </>
);
```

> **Note:** This declaration is required when using bundlers like Vite or webpack with an SVG loader (e.g., `@svgr/webpack`). Without it, TypeScript will throw a "Cannot find module" error on `.svg` imports. This file is part of the [Major League GitHub](https://github.com/flamingo-stack/major-league-github) frontend and assumes the bundler is configured to handle both SVGR component transforms and URL exports.
