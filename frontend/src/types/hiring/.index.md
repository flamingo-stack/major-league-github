TypeScript interface definitions for the Hiring Manager feature, defining the data shapes for social links, job openings, and hiring manager profiles.

## Key Components

| Export | Description |
|---|---|
| `SocialLink` | A social media link with a constrained `platform` union type (`linkedin`, `twitter`, or `github`) and a URL string |
| `JobOpening` | Represents a job listing with an ID, title, location, and application URL |
| `HiringManagerProfile` | A complete hiring manager profile including name, avatar, role, bio, and an array of `SocialLink` entries |

## Usage Example

```typescript
import { HiringManagerProfile, JobOpening, SocialLink } from './index';

const socialLinks: SocialLink[] = [
  { platform: 'github', url: 'https://github.com/jdoe' },
  { platform: 'linkedin', url: 'https://linkedin.com/in/jdoe' },
];

const manager: HiringManagerProfile = {
  name: 'Jane Doe',
  avatarUrl: 'https://example.com/avatar.png',
  role: 'Engineering Manager',
  bio: 'Passionate about open source and developer tooling.',
  socialLinks,
};

const opening: JobOpening = {
  id: 'eng-001',
  title: 'Senior Backend Engineer',
  location: 'Remote',
  url: 'https://example.com/jobs/eng-001',
};
```
