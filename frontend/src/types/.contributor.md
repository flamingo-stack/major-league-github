Defines the `Contributor` interface, the core data model representing a ranked GitHub contributor on the Major League GitHub leaderboard.

## Key Components

### `Contributor` Interface

The primary export describing a fully-resolved contributor record, combining raw GitHub activity metrics with computed ranking data and geographic context.

| Field | Type | Description |
|---|---|---|
| `login` | `string` | GitHub username |
| `name` | `string \| null` | Display name |
| `avatarUrl` | `string` | GitHub avatar image URL |
| `url` | `string` | GitHub profile URL |
| `totalCommits` | `number` | Total commits across all repos |
| `starsReceived` | `number` | Stars earned on owned repos |
| `starsGiven` | `number` | Stars given to other repos |
| `forksReceived` | `number` | Times repos have been forked |
| `forksGiven` | `number` | Repos forked by the contributor |
| `javaRepos` | `number` | Number of Java repositories |
| `latestCommitDate` | `string` | ISO date string of most recent commit |
| `score` | `number` | Computed leaderboard ranking score |
| `city` | `City` | Resolved geographic city (from `api` types) |
| `nearestTeam` | `SoccerTeam \| null` | Closest MLS team to the contributor's location |
| `location` | `string \| null` | Raw location string from GitHub profile |
| `contributions` | `number` | Total contribution count |

## Usage Example

```typescript
import { Contributor } from './models/contributor';

function renderPlayerCard(contributor: Contributor): string {
  const team = contributor.nearestTeam?.name ?? 'Unaffiliated';
  return `${contributor.name ?? contributor.login} — ${team} | Score: ${contributor.score}`;
}
```
