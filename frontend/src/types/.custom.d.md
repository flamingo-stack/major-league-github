Extends TypeScript's module resolution to treat imported SVG files as React components rather than raw strings.

## Key Components

- **`*.svg` module declaration** — wildcard ambient module that types any `.svg` import as a `React.FunctionComponent` accepting standard `SVGSVGElement` props.

## Usage Example

```typescript
import Logo from './logo.svg';

const Header = () => (
  <Logo width={48} height={48} aria-label="Logo" />
);
```

## Notes

- Enables full SVG prop type-checking (`width`, `height`, `fill`, `className`, etc.) via `React.SVGProps<SVGSVGElement>`.
- Requires a bundler transform (e.g., SVGR via Vite or Create React App) to actually inline SVGs as React components at runtime — this file only satisfies the TypeScript compiler.
