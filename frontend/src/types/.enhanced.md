Extends base API types (`City`, `Region`, `State`) with fully resolved object references instead of raw IDs or nullable primitives.

## Key Components

| Type | Description |
|---|---|
| `EnhancedCity` | Extends `City` with `state` resolved to a `State` object and `nearestTeam` resolved to a `SoccerTeam` object (both nullable) |
| `EnhancedRegion` | Extends `Region` with `states` and `cities` as `Set` collections of full objects |
| `EnhancedState` | Extends `State` with `regionIds` string array plus `regions` and `cities` as `Set` collections |

## Usage Example

```typescript
import { EnhancedCity, EnhancedRegion, EnhancedState } from './enhanced';

const city: EnhancedCity = {
  id: 'nyc',
  name: 'New York',
  state: { id: 'ny', name: 'New York', abbreviation: 'NY' },
  nearestTeam: { id: 'rbny', name: 'Red Bulls', ... },
};

const region: EnhancedRegion = {
  id: 'northeast',
  name: 'Northeast',
  states: new Set([...]),
  cities: new Set([...]),
};

const state: EnhancedState = {
  id: 'ny',
  name: 'New York',
  abbreviation: 'NY',
  regionIds: ['northeast'],
  regions: new Set([...]),
  cities: new Set([...]),
};
```

These types are typically populated during cache hydration, where raw API responses are cross-referenced and assembled into fully linked in-memory structures.
