Core API type definitions for the Major League GitHub frontend, providing typed interfaces for all REST API responses and domain entities returned by the backend service.

## Key Components

| Export | Description |
|---|---|
| `ApiResponse<T>` | Generic wrapper for all API responses with `status`, `message`, and typed `data` payload |
| `City` | Geographic city entity with coordinates, state reference, and nearest MLS team |
| `Region` | Multi-state geographic grouping with centroid coordinates |
| `State` | US state with display metadata and icon |
| `Language` | Programming language filter option with display metadata |
| `SoccerTeam` | MLS team entity with stadium, coach, and geographic data |
| `Contributor` | Core ranked user entity combining GitHub stats, location, and soccer team proximity |

## Usage Example

```typescript
import { ApiResponse, Contributor, SoccerTeam, Language } from './api';

// Fetch top contributors for a given language
async function fetchContributors(languageId: string): Promise<Contributor[]> {
  const res = await fetch(`/api/contributors?languageId=${languageId}`);
  const json: ApiResponse<Contributor[]> = await res.json();

  if (json.status !== 'success') {
    throw new Error(json.message);
  }

  return json.data;
}

// Access nested stats and nearest team
function renderContributorCard(c: Contributor) {
  const team: SoccerTeam | null = c.nearestTeam;
  const score: number = c.githubStats.score;

  console.log(`${c.login} — Score: ${score}, Nearest team: ${team?.name ?? 'N/A'}`);
}
```

## Notes

- `Contributor.lastActive` is a Unix timestamp in **seconds**, not milliseconds — divide by `1` when passing to `new Date()` or multiply by `1000`.
- `City` and `Region` include optional reference objects (`state`, `nearestTeam`, `states`) that may be absent depending on the API endpoint.
- `Contributor.type` distinguishes regular contributors from `'HIRING_MANAGER'` profiles used in the [hiring feature](https://github.com/flamingo-stack/major-league-github/blob/main/src/types/hiring.ts).
