Centralizes all color mappings from hardcoded GitHub-style hex values to the ODS (OpenFrame Design System) color tokens, providing a single source of truth for theme conversions across the frontend.

## Key Components

### Color Map Objects

| Export | Purpose |
|---|---|
| `githubToOds` | Maps semantic UI roles (text, background, border, link, status) to ODS color tokens |
| `badgeColors` | Gold/silver/bronze badge styles with hex-opacity variants for ranking displays |
| `shadows` | Light, medium, heavy, and card shadow values at fixed opacity levels |

### Helper Functions

| Function | Signature | Description |
|---|---|---|
| `getGithubColor` | `(key: GithubColorKey) => string` | Retrieves a color from `githubToOds` by semantic key |
| `getBadgeColor` | `(type: BadgeColorType, variant: BadgeColorVariant) => string` | Retrieves a specific badge color variant |
| `getShadowColor` | `(type: ShadowType) => string` | Retrieves a shadow color by intensity level |

### Type Exports

`GithubColorKey`, `BadgeColorType`, `BadgeColorVariant`, `ShadowType` — narrow TypeScript types derived from the const objects for type-safe usage throughout the codebase.

## Usage Example

```typescript
import {
  getGithubColor,
  getBadgeColor,
  getShadowColor,
  githubToOds,
  badgeColors,
} from './colorMappings';

// Retrieve a semantic color token
const linkColor = getGithubColor('link');         // flamingo.cyan_light
const errorColor = getGithubColor('error');       // attention.red_error

// Apply a ranked badge style
const goldBg     = getBadgeColor('gold', 'bg');          // openYellow.base + '1A' (10% opacity)
const silverText = getBadgeColor('silver', 'text');      // systemGreys.grey

// Use a shadow level
const cardShadow = getShadowColor('card');        // systemGreys.black + 'B3' (70% opacity)

// Direct object access (fully typed)
const hoverBorder: string = badgeColors.bronze.borderHover;
```
