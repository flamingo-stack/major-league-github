Centralized color token definitions extracted from the Flamingo UI kit, providing typed access to base, semantic, and categorized color values for use across the frontend.

## Key Components

| Export | Type | Description |
|---|---|---|
| `baseColors` | `const object` | Raw design tokens: attention, flamingo cyan/pink, open yellow, and system grey palettes |
| `semanticColors` | `const object` | Role-based colors (text, background, accent, focus, warning, etc.) |
| `colors` | `const object` | Merged export of all base and semantic colors |
| `ColorKey` | `type` | Union type of all valid color keys derived from `colors` |
| `getColor` | `function` | Type-safe helper to retrieve a color hex value by key |
| `attention` | `const object` | Scoped category: success green and error red variants |
| `flamingo` | `const object` | Scoped category: cyan and pink brand color variants |
| `openYellow` | `const object` | Scoped category: yellow brand color variants |
| `systemGreys` | `const object` | Scoped category: background, black, grey, soft grey, and white variants |

## Usage Example

```typescript
import { getColor, flamingo, systemGreys, ColorKey } from './colors';

// Type-safe lookup by key
const errorColor = getColor('attention_red_error'); // '#f36666'

// Category-scoped access
const brandCyan = flamingo.cyan_base;       // '#5efaf0'
const pageBg   = systemGreys.background;    // '#161616'

// Use ColorKey for typed props
function applyColor(key: ColorKey): void {
  const hex = getColor(key);
  document.body.style.backgroundColor = hex;
}
```

> **Note:** Colors are auto-generated from `ui-kit/src/styles/ods_color_tokens.json` and `ods-colors.css` via [`scripts/extract-ui-kit-colors.js`](https://github.com/flamingo-stack/major-league-github/blob/main/scripts/extract-ui-kit-colors.js). Edit the source design tokens rather than this file directly.
