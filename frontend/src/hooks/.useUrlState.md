Manages filter state in the browser URL query string, providing validated reads and debounced writes for Major League GitHub's city, region, state, language, and team filter parameters.

## Key Components

| Export | Type | Description |
|---|---|---|
| `UrlState` | Interface | Shape of all URL-driven filter parameters (`selectedCityId`, `selectedRegionId`, `stateId`, `languageId`, `teamId`) |
| `UseUrlStateOptions` | Interface | Hook options: `onError` callback and optional `debounceMs` delay |
| `useUrlState` | Hook | Reads, writes, validates, and debounces URL search params |
| `URL_PARAMS` | Constant | Maps each `UrlState` key to its query-string key and a `^[a-zA-Z0-9-]+$` validator |
| `UrlStateError` | Class | Custom error carrying the failing `param` name, surfaced via `onError` |

The hook returns:

- `urlState` — memoized, validated snapshot of current search params
- `updateUrlState(partial, { immediate? })` — merges partial state into the URL; skips if no values changed; debounces by `debounceMs` unless `immediate` is `true` or the value is being cleared
- `resetUrlState()` — removes all managed params
- `hasStateChanged` — `true` when the parsed state differs from the previous render
- `isStateEmpty` — `true` when every param is `null`

## Usage Example

```typescript
import { useUrlState } from './useUrlState';

function FilterPanel() {
  const { urlState, updateUrlState, resetUrlState, isStateEmpty } = useUrlState({
    debounceMs: 300,
    onError: (err) => console.warn('Bad URL param:', err.param, err.message),
  });

  return (
    <>
      <LanguagePicker
        value={urlState.languageId}
        onChange={(id) => updateUrlState({ languageId: id })}
      />
      <CityPicker
        value={urlState.selectedCityId}
        onChange={(id) => updateUrlState({ selectedCityId: id }, { immediate: true })}
      />
      {!isStateEmpty && (
        <button onClick={resetUrlState}>Clear all filters</button>
      )}
    </>
  );
}
```

Invalid param values fall back to `null` silently; the `onError` callback is the recommended surface for logging or user-facing warnings.
