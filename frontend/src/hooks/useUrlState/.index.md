Manages leaderboard filter state by syncing it with the browser's URL query parameters, enabling shareable and bookmarkable filter combinations.

## Key Components

### `UrlState` Interface
Defines the shape of URL-driven filter state:

| Field | Query Param | Description |
|---|---|---|
| `selectedCityId` | `cityId` | MLS stadium city filter |
| `selectedRegionId` | `regionId` | Geographic region filter |
| `stateId` | `stateId` | U.S. state filter |
| `teamId` | `teamId` | MLS team filter |
| `languageId` | `languageId` | Programming language filter |

### `useUrlState` Hook
Reads and writes all filter parameters from `URLSearchParams`. Setting a value to `null` removes the parameter from the URL entirely, keeping URLs clean.

## Usage Example

```typescript
import { useUrlState } from './hooks/useUrlState';

function FilterPanel() {
  const { urlState, updateUrlState } = useUrlState();

  // Read current filter state
  const { languageId, teamId } = urlState;

  // Apply a language filter
  const handleLanguageSelect = (id: string) => {
    updateUrlState({ languageId: id });
  };

  // Clear a single filter without touching others
  const handleClearTeam = () => {
    updateUrlState({ teamId: null });
  };

  return (/* ... */);
}
```

> Partial updates merge with existing query params — only the keys passed to `updateUrlState` are affected, leaving unrelated filters intact.
