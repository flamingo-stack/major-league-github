Provides a custom React hook that fetches and returns a list of GitHub contributors based on the current URL filter state, using React Query for data fetching and caching.

## Key Components

- **`useContributors`** — Custom hook that combines `useUrlState` and `useQuery` to fetch contributors filtered by city, region, state, team, and language. Returns `contributors`, `isLoading`, and `error`.

## Usage Example

```typescript
import { useContributors } from './hooks/useContributors';

const LeaderboardTable = () => {
  const { contributors, isLoading, error } = useContributors();

  if (isLoading) return <p>Loading...</p>;
  if (error) return <p>Error loading contributors.</p>;

  return (
    <ul>
      {contributors?.map((c) => (
        <li key={c.id}>{c.login}</li>
      ))}
    </ul>
  );
};
```

## Behavior Notes

- **Fetch guard** — Queries are disabled until a `languageId` is present in URL state; no request is made without a selected language.
- **Retry logic** — Skips retries entirely on known server errors (`"Server is currently unavailable"`, `"Cache is still being populated"`); retries up to 3 times for all other errors.
- **Backoff** — Uses exponential backoff (`1000 * 2^attempt`), capped at 30 seconds.
- **Max results** — Fetches up to 15 contributors per query.
