Provides a unified React Query hook that fetches and caches both hiring manager profile data and job openings from the hiring service layer.

## Key Components

- **`useHiring`** — Custom hook that composes two `useQuery` calls and exposes a single, combined loading/error state for consumers.

| Query Key | Fetcher | Cache TTL |
|---|---|---|
| `hiringManager` | `fetchHiringManagerProfile` | 5 minutes |
| `jobOpenings` | `fetchJobOpenings` | 5 minutes |

**Retry logic:** Both queries suppress retries on `"Failed to fetch"` network errors (indicating a permanent failure), and allow up to 3 retries for all other error types.

## Usage Example

```typescript
import { useHiring } from './hooks/hiring';

const HiringPanel = () => {
  const { hiringManager, jobOpenings, isLoading, error } = useHiring();

  if (isLoading) return <Spinner />;
  if (error) return <ErrorMessage error={error} />;

  return (
    <>
      <ManagerCard manager={hiringManager} />
      <JobList openings={jobOpenings} />
    </>
  );
};
```

## Return Shape

```typescript
{
  hiringManager: HiringManagerProfile | undefined;
  jobOpenings: JobOpening[] | undefined;
  isLoading: boolean;   // true if either query is in-flight
  error: Error | null;  // first error encountered, or null
}
```
