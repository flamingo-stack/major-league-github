A React hook that uses the browser's Geolocation API to automatically identify the nearest geographic region (e.g., MLS stadium area) from a list of `Region` objects, using the Haversine formula for accurate great-circle distance calculations.

## Key Components

- **`getDistance(coords1, coords2)`** — Private helper implementing the Haversine formula to compute the distance in kilometers between two lat/lon coordinate pairs on Earth's surface.
- **`useNearestRegion(regions)`** — Primary exported hook that accepts an array of `Region` objects and returns the nearest one to the user's current position.
- **`nearestRegion`** — State value containing the closest `Region`, or `null` if not yet resolved.
- **`error`** — State value containing a human-readable error message if geolocation is unsupported, denied, or no regions have coordinates.

## Behavior Notes

- Regions missing `geo.latitude` or `geo.longitude` are skipped silently.
- The effect re-runs whenever the `regions` array reference changes.
- Geolocation is requested once on mount (or when `regions` updates); no continuous tracking is performed.

## Usage Example

```typescript
import { useNearestRegion } from './hooks/useNearestRegion';
import { Region } from './types/api';

function RegionSelector({ regions }: { regions: Region[] }) {
  const { nearestRegion, error } = useNearestRegion(regions);

  if (error) return <p>Location unavailable: {error}</p>;
  if (!nearestRegion) return <p>Detecting your nearest region...</p>;

  return <p>Nearest region: {nearestRegion.name}</p>;
}
```

## Error States

| Scenario | `error` value |
|---|---|
| Browser lacks Geolocation API | `'Geolocation is not supported by your browser'` |
| User denies location permission | `'Unable to retrieve your location'` |
| No regions have coordinates | `'No regions with coordinates found'` |
