Composite React Query hook that fetches both hiring manager profile and job openings data in parallel, exposing a unified loading and error state.

## Key Components

- **`useHiring`** — Custom hook that runs two concurrent `useQuery` calls:
  - `hiringManager` — Result from `getHiringManagerProfile`, keyed by `['hiringManager']`
  - `jobOpenings` — Result from `getJobOpenings`, keyed by `['jobOpenings']`, defaults to `[]` if undefined
  - `isLoading` — `true` if either query is still fetching
  - `error` — First error encountered across either query (manager error takes precedence)
  - Both queries are configured with `retry: 1` to attempt one re-fetch on failure

## Usage Example

```typescript
import { useHiring } from './hooks/useHiring';

const HiringSection = () => {
  const { hiringManager, jobOpenings, isLoading, error } = useHiring();

  if (isLoading) return <p>Loading...</p>;
  if (error) return <p>Failed to load hiring data.</p>;

  return (
    <>
      <h2>Contact: {hiringManager?.name}</h2>
      <ul>
        {jobOpenings.map((job) => (
          <li key={job.id}>{job.title}</li>
        ))}
      </ul>
    </>
  );
};
```

## Notes

- Queries run independently and in parallel — a failure in one does not block the other.
- `jobOpenings` is always an array (never `undefined`), safe to map without a guard.
- Error reporting surfaces only the first error; check both `managerError` and `jobsError` directly if granular error handling is needed.
