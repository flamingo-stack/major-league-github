Defines and exports the Material-UI dark theme for the Major League GitHub frontend, mapping ODS (design system) color tokens to MUI palette roles and component style overrides.

## Key Components

- **`odsColors`** — Internal color alias map that translates `systemGreys`, `flamingo`, and `attention` tokens into semantic neutral/blue/green scales used throughout the theme.
- **`getTheme()`** — Factory function that calls `createTheme()` and returns the fully configured MUI theme. Covers:
  - **Palette** — Dark mode with flamingo cyan as primary, ODS success green, and a grey neutral scale for backgrounds, text, and dividers.
  - **Typography** — DM Sans font family with six heading variants (h1–h4), two body styles, and sentence-case buttons.
  - **Component overrides** — Custom styles for `MuiButton`, `MuiTableCell`, `MuiPaper`, `MuiAppBar`, `MuiTextField`, `MuiAutocomplete`, and `MuiLink`.

## Usage Example

```typescript
import { ThemeProvider, CssBaseline } from '@mui/material';
import { getTheme } from './theme';

const theme = getTheme();

export default function App() {
  return (
    <ThemeProvider theme={theme}>
      <CssBaseline />
      {/* Application content */}
    </ThemeProvider>
  );
}
```

> **Note:** `getTheme()` is a factory rather than a static export to allow future support for runtime theme switching (e.g., light/dark toggle) without refactoring call sites.
