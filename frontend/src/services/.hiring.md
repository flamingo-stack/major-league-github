Async service function that fetches job openings from the backend API, returning an empty array on failure instead of propagating errors.

## Key Components

- **`fetchJobOpenings`** — Async function that calls `getJobOpenings()` from the API layer, catches any errors silently (logging to console), and returns a `JobOpening[]` array.

## Usage Example

```typescript
import { fetchJobOpenings } from './hiring';

const openings = await fetchJobOpenings();

if (openings.length === 0) {
  console.log('No job openings available.');
} else {
  openings.forEach(job => console.log(job.title));
}
```

## Notes

- Errors are swallowed and logged via `console.error`; callers receive an empty array rather than a thrown exception.
- The `JobOpening` type is imported from `../types/hiring` — ensure that type definition stays in sync with the backend API response shape.
