Centralized API client for the Major League GitHub frontend, wrapping all backend HTTP calls via axios with typed request/response handling.

## Key Components

| Export | Description |
|---|---|
| `getContributors(params)` | Fetches a filtered, paginated list of GitHub contributors by city, region, state, MLS team, or language |
| `downloadContributors(params)` | Triggers a CSV export download by injecting a temporary `<a>` element into the DOM |
| `autocompleteRegions/States/Cities/Languages/Teams` | Typeahead search functions for each filter dimension, all accepting an optional `AbortSignal` for cancellation |
| `getRegionById/getStateById/getCityById/getLanguageById/getTeamById` | Entity lookup functions that resolve a filter ID to its full typed object |
| `getHiringManagerProfile` | Fetches the hiring manager profile from `/api/hiring/manager` |
| `getJobOpenings` | Fetches available job openings from `/api/hiring/jobs` |

All functions throw an `Error` if the backend returns a non-`success` status, surfacing the backend's `message` field directly.

## Usage Example

```typescript
import { getContributors, autocompleteLanguages, downloadContributors } from './services/api';

// Fetch top 10 contributors filtered by MLS team and language
const contributors = await getContributors({
  teamId: 'mls-atlanta-united',
  languageId: 'typescript',
  maxResults: 10,
  signal: abortController.signal,
});

// Typeahead search for programming languages
const languages = await autocompleteLanguages('rust', abortController.signal);

// Trigger a CSV download with the current filters
downloadContributors({ teamId: 'mls-atlanta-united', languageId: 'typescript' });
```

The base URL is resolved from the `BACKEND_API_URL` environment variable at startup, defaulting to `/` for same-origin deployments. See the [source file](https://github.com/flamingo-stack/major-league-github/blob/main/frontend/src/services/api.ts) for the full type definitions.
