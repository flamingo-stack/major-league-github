Async helper functions that enrich flat API response objects (`City`, `Region`, `State`) with resolved relational data, producing richer `Enhanced*` variants used throughout the frontend.

## Key Components

| Export | Input → Output | Description |
|---|---|---|
| `enhanceCity` | `City` → `EnhancedCity` | Resolves `stateId` and optional `nearestTeamId` into full objects via parallel API calls |
| `enhanceRegion` | `Region` → `EnhancedRegion` | Resolves all `stateIds` into `State` objects in parallel; initializes an empty `cities` Set |
| `enhanceState` | `State` → `EnhancedState` | Wraps a `State` with empty `regions` and `cities` Sets for downstream population |

## Usage Example

```typescript
import { enhanceCity, enhanceRegion, enhanceState } from './enhanced';

// Enrich a city returned from the API
const rawCity = await getCityById(42);
const city = await enhanceCity(rawCity);
console.log(city.state?.name);       // resolved State object
console.log(city.nearestTeam?.name); // resolved Team object, or null

// Enrich a region (states resolved in parallel)
const rawRegion = await getRegionById(7);
const region = await enhanceRegion(rawRegion);
region.states.forEach(s => console.log(s.name));

// Wrap a state for further population
const rawState = await getStateById(5);
const state = await enhanceState(rawState);
```

## Notes

- `enhanceCity` uses `Promise.all` to fetch state and team concurrently, avoiding sequential round-trips. Team fetch is skipped when `nearestTeamId` is absent.
- `enhanceRegion` filters out any `null` results from failed state lookups before building the `Set`.
- `enhanceState` and `enhanceRegion` return empty `cities`/`regions` Sets — callers are expected to populate these separately.
