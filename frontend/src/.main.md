The React application entry point that bootstraps the app by mounting the root `App` component into the DOM with React's Strict Mode enabled.

## Key Components

- **`ReactDOM.createRoot`** — Creates a concurrent-mode React root targeting the `#root` DOM element
- **`React.StrictMode`** — Wraps the app to surface potential issues during development
- **`App`** — The top-level application component rendered into the root

## Usage Example

```typescript
// This file is not imported directly — it is the Vite entry point.
// The #root element in index.html serves as the mount target:

// index.html
// <div id="root"></div>
// <script type="module" src="/src/main.tsx"></script>
```

> **Note:** This file runs automatically when the app starts. No manual invocation is needed. To change global styles or providers, wrap `<App />` inside additional context providers here before the `render` call.
