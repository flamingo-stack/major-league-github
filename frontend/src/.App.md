The root React application component that bootstraps the Major League GitHub frontend, wiring together routing, data fetching, theming, and layout.

## Key Components

- **`App`** — Top-level export that wraps the application in `BrowserRouter` and `QueryClientProvider` with a pre-configured `QueryClient` (no retry, no window-focus refetch).
- **`MainApp`** — Inner component that reads URL-driven filter state via `useUrlState`, fetches contributors from the API using `useQuery`, and renders the themed `Layout` containing `FiltersPanel` and `ContributorsTable`.
- **`queryClient`** — Singleton `QueryClient` configured to refetch on mount only, with retries disabled.

## Data Flow

Filter parameters (`cityId`, `regionId`, `stateId`, `languageId`, `teamId`) are read from the URL state and used as the React Query cache key. Any URL change automatically invalidates the cache and re-fetches up to 15 contributors via `getContributors`.

## Usage Example

```typescript
// Entry point (main.tsx)
import React from 'react';
import ReactDOM from 'react-dom/client';
import App from './App';

ReactDOM.createRoot(document.getElementById('root')!).render(
  <React.StrictMode>
    <App />
  </React.StrictMode>
);
```

The `App` component is self-contained — no props required. All filter state is managed via URL query parameters, so deep-linking to a filtered view (e.g. `?languageId=typescript&teamId=5`) works out of the box.
