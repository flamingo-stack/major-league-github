A minimal stub component that satisfies `ui-kit` persistent-pagination import requirements. Returns `null` when there is only one page, otherwise renders previous/next navigation and up to five numbered page buttons.

## Key Components

- **`BlogPaginationProps`** — Interface defining the component's props
  - `currentPage: number` — The currently active page (1-based)
  - `totalPages: number` — Total number of pages available
  - `onPageChange?: (page: number) => void` — Optional callback fired when the user selects a page

- **`BlogPagination`** — Named export rendering a centered pagination bar with previous/next buttons and numbered page indicators (capped at 5)

## Usage Example

```typescript
import { BlogPagination } from './blog-pagination';

function PostList() {
  const [currentPage, setCurrentPage] = useState(1);
  const totalPages = 8;

  return (
    <>
      {/* post list content */}
      <BlogPagination
        currentPage={currentPage}
        totalPages={totalPages}
        onPageChange={(page) => setCurrentPage(page)}
      />
    </>
  );
}
```

## Notes

- Returns `null` immediately when `totalPages <= 1`, so it is safe to render unconditionally.
- The page-number row displays at most 5 buttons regardless of `totalPages`; pages beyond 5 are not reachable via numbered buttons.
- Styling uses Tailwind CSS utility classes. The active page button is highlighted with `bg-blue-600 text-white`; inactive buttons show `text-gray-600` with a hover state.
