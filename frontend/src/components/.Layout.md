Root page layout wrapper that composes the app shell: a sticky `Header`, full-width `HeroSection`, a scrollable content area, and a conditionally rendered fixed-bottom `HiringSection` footer.

## Key Components

- **`Layout`** — Default page wrapper accepting `children` as its content slot
- **`useHiring`** — Hook that supplies `hiringManager`, `jobOpenings`, and `isLoadingHiring` state; the sticky footer only renders once loading completes and both values are available
- **`HiringSection`** — Fixed-position footer rendered at `zIndex: 2000`; hidden until hiring data is ready to avoid layout flash
- **`Container`** — MUI `maxWidth="xl"` content area with `mb: '200px'` bottom margin to prevent the sticky footer from obscuring page content

## Usage Example

```typescript
import { Layout } from './components/Layout';

function App() {
  return (
    <Layout>
      <LeaderboardTable />
      <FilterPanel />
    </Layout>
  );
}
```

## Notes

- The outer `Box` fills the full viewport height (`minHeight: '100vh'`) using a flex column, ensuring the content area grows to push the footer correctly.
- The hiring footer is gated on `!isLoadingHiring && hiringManager && jobOpenings`, so it never renders with incomplete data.
- Background color is sourced from `systemGreys.background` for consistent theming across the shell.
