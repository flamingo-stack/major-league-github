A generic, reusable MUI Autocomplete wrapper that standardizes entity selection with icon/logo support across the Major League GitHub frontend.

## Key Components

### `BaseEntity` Interface
Defines the minimum shape required for autocomplete options, with fields for `id`, `name`, `displayName`, `iconUrl`, and `logoUrl`.

### `BaseAutocompleteProps<T>` Interface
Typed props for the component, supporting:
- **Controlled state:** `value`, `onChange`, `inputValue`, `onInputChange`
- **Options and display:** `options`, `placeholder`, `getOptionLabel`
- **Custom rendering:** `renderIcon` (defaults to `iconUrl ?? logoUrl`), `renderOptionContent` for fully custom option rows
- **Styling:** `sx` passthrough to MUI

### `BaseAutocomplete<T>` Component
A generic `freeSolo` MUI `Autocomplete` with:
- **Icon adornment** in the text field when a value is selected
- **Clear handling** that resets both input text and selected value
- **Blur normalization** that restores the display label if a value is already selected
- **Default option renderer** showing a 24×24 icon alongside the label; overridable via `renderOptionContent`

## Usage Example

```typescript
import { BaseAutocomplete, BaseEntity } from './BaseAutocomplete';

interface Language extends BaseEntity {
  color: string;
}

const languages: Language[] = [
  { id: 'ts', name: 'TypeScript', iconUrl: '/icons/ts.svg', color: '#3178c6' },
];

<BaseAutocomplete<Language>
  value={selectedLanguage}
  onChange={setSelectedLanguage}
  inputValue={inputText}
  onInputChange={setInputText}
  options={languages}
  placeholder="Filter by language"
  getOptionLabel={(opt) => opt.name ?? opt.id}
/>
```
