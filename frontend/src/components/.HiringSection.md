Collapsible footer section that displays a hiring manager's profile, social links, job openings count, and GitHub stats, with an expandable panel toggled by clicking the preview bar.

## Key Components

- **`HiringSection`** — Main exported component
- **`HiringSectionProps`** — Interface accepting `hiringManager`, `jobOpenings`, `isLoading`, and `error`
- **`getSocialIcon`** — Helper that maps platform name strings to MUI/custom icon elements
- **`isExpanded`** — Local state controlling the `Collapse` panel visibility

### Layout Sections

| Section | Description |
|---|---|
| Preview Bar | Always-visible two-row footer strip with branding, avatar, open position count, and expand toggle |
| Expanded Panel | `Collapse`-animated `Paper` containing hiring manager profile, `GitHubStats`, social links, and job openings |
| Mobile Close Button | Sticky `IconButton` inside the expanded panel, visible only on `xs` breakpoints |

## Usage Example

```typescript
import { HiringSection } from './HiringSection';
import { HiringManagerProfile, JobOpening } from '../types/hiring';

const manager: HiringManagerProfile = {
  name: 'Jane Smith',
  role: 'Engineering Manager',
  avatarUrl: 'https://example.com/avatar.png',
  bio: 'Building great teams...',
  githubStats: { repos: 42, stars: 300 },
  lastActive: '2024-01-15',
  socialLinks: [{ platform: 'linkedin', url: 'https://linkedin.com/in/jane' }],
};

const openings: JobOpening[] = [
  { id: '1', title: 'Senior Engineer', department: 'Engineering' }
];

<HiringSection
  hiringManager={manager}
  jobOpenings={openings}
  isLoading={false}
  error={null}
/>
```

> **Note:** The expanded panel only renders when there is no `error` and either `isLoading` is `true` or a `hiringManager` object is present, preventing an empty collapsed state.
