Renders a Material-UI data table for the GitHub contributors leaderboard, displaying ranked contributor stats with tooltips, social links, and loading/error states.

## Key Components

- **`TableView`** — Primary export. Accepts `ContributorsTableProps` (`contributors`, `isLoading`, `error`) and renders a full leaderboard table with six columns: Contributor, Location, Score, Activity, Engagement, and Last Active.
- **`getSocialIcon`** — Helper that maps a platform name string (`'linkedin'`, `'twitter'`, `'github'`, etc.) to its corresponding MUI or custom icon element.
- **`StatPill`** — Internal inline component that wraps stat values in a styled pill/badge box.
- **`ScoreTooltip`** — Internal component rendered inside an MUI `Tooltip` that shows a breakdown of a contributor's score (commits, stars, recency multiplier) with an expandable formula section.

## Usage Example

```typescript
import { TableView } from './components/ContributorsTable/views/TableView';

<TableView
  contributors={contributors}
  isLoading={isFetching}
  error={fetchError}
/>
```

The component handles all three states internally:

- **Loading** — renders `<LoadingSpinner message="Loading contributors..." />`
- **Error** — renders `<ErrorMessage>` with the error message
- **Empty** — renders `<ErrorMessage message="No contributors found" />`

Column icons use `githubToOds` color tokens from the shared style mappings. The `useHiring` hook is consumed to expose a `hiringManager` context, used downstream to tag hireable contributors within `ContributorInfo`.
