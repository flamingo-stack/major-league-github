Mobile-optimized card list view for rendering GitHub contributor leaderboard entries, displaying contributor stats, location, and social links in a responsive stacked layout.

## Key Components

- **`MobileView`** – Main exported component that accepts `ContributorsTableProps` (`contributors`, `isLoading`, `error`) and renders a vertically stacked list of contributor cards with loading/error/empty states.
- **`StatItem`** – Internal inline component rendering a single icon-plus-value badge (score, commits, repos, stars, forks, last active date) with consistent pill styling.
- **`getSocialIcon`** – Helper that maps a platform name string (`linkedin`, `twitter`, `github`, `facebook`, `instagram`, `email`, `website`) to the corresponding MUI or custom icon element.

## Usage Example

```typescript
import { MobileView } from './MobileView';

<MobileView
  contributors={contributors}
  isLoading={isLoading}
  error={error}
/>
```

## Notes

- Uses `ContributorInfo` and `LocationInfo` sub-components for avatar/rank/name and geographic data respectively.
- Integrates `useHiring` to surface the hiring manager's GitHub username for the join-team CTA inside `ContributorInfo`; the button is hidden below 440 px via a media query.
- Stats are formatted with `formatNumber` (abbreviated counts) and `formatDate` (human-readable last-active date).
- Theming is driven by `githubToOds` color mappings to maintain visual consistency with the rest of the leaderboard.
