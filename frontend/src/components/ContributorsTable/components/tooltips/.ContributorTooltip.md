Renders a tooltip card displaying a GitHub contributor's profile summary, including their avatar, display name, location, and key GitHub stats.

## Key Components

**`ContributorTooltipContent`** — A functional React component that accepts a `ContributorTooltipProps` object and renders a structured MUI `Box` layout with:

- **Avatar + Identity** — Contributor photo, display name (falls back to login), and username
- **Location** — Optional city/state display with a `LocationOnIcon`, rendered only when `contributor.city` is defined
- **Stats Row** — Stars received, total commits, and Java repository count, each formatted with `toLocaleString()`

All colors are sourced from the `githubToOds` mapping in `styles/colorMappings`, keeping the tooltip visually consistent with the app's design system.

## Usage Example

```typescript
import { ContributorTooltipContent } from './components/ContributorTooltip';
import { Tooltip } from '@mui/material';

<Tooltip
  title={<ContributorTooltipContent contributor={contributor} />}
  arrow
>
  <span>{contributor.login}</span>
</Tooltip>
```

Where `contributor` satisfies the `ContributorTooltipProps` interface shape:

```typescript
const contributor = {
  login: 'octocat',
  name: 'The Octocat',
  avatarUrl: 'https://avatars.githubusercontent.com/u/583231',
  city: { name: 'San Francisco', state: { code: 'CA' } },
  starsReceived: 4200,
  totalCommits: 1337,
  javaRepos: 12,
};
```
