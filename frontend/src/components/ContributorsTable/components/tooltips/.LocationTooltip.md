A React tooltip content component that displays detailed MLS team information for a contributor's nearest stadium location.

## Key Components

**`LocationTooltipContent`** — The sole export; a functional component that renders a styled tooltip panel with:
- **Team header** — logo, name, city, and state
- **Stadium details** — name and seating capacity
- **Team metadata** — MLS join year and head coach
- **External links** — official team website and Wikipedia page, both opening in a new tab

Returns `null` if the contributor has no `nearestTeam` assigned.

## Usage Example

```typescript
import { LocationTooltipContent } from './LocationTooltip';
import { Tooltip } from '@mui/material';

const contributor = {
  nearestTeam: {
    name: 'Portland Timbers',
    city: 'Portland',
    state: 'OR',
    logoUrl: 'https://example.com/timbers.png',
    stadium: 'Providence Park',
    stadiumCapacity: 25218,
    joinedYear: 2011,
    headCoach: 'Phil Neville',
    teamUrl: 'https://www.timbers.com',
    wikipediaUrl: 'https://en.wikipedia.org/wiki/Portland_Timbers',
  },
};

<Tooltip title={<LocationTooltipContent contributor={contributor} />}>
  <span>📍 Portland, OR</span>
</Tooltip>
```

Props are typed via `LocationTooltipProps` from `../../types`. Colors are sourced from the shared `githubToOds` mapping in [`styles/colorMappings`](https://github.com/flamingo-stack/major-league-github/blob/main/styles/colorMappings.ts).
