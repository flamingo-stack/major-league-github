Renders a tooltip panel displaying detailed information about the MLS team nearest to a contributor, including the team logo, location, stadium, coach, and external links.

## Key Components

### `TeamTooltipContent`

A functional React component that accepts a single prop:

| Prop | Type | Description |
|------|------|-------------|
| `team` | `NonNullable<Contributor['nearestTeam']>` | The MLS team object associated with a contributor |

**Rendered details:**

- **Header** — Team logo (`Avatar`) alongside the team name and city/state
- **Stadium row** — Stadium name with formatted seating capacity
- **MLS join year** — Year the team entered Major League Soccer
- **Head coach** — Current head coach name
- **External links** — Opens the team's official website and Wikipedia page in new tabs

Styling is applied via MUI's `sx` prop using tokens from the shared `githubToOds` color mapping.

## Usage Example

```typescript
import { TeamTooltipContent } from './TeamTooltip';

const nearestTeam = contributor.nearestTeam;

if (nearestTeam) {
  return (
    <Tooltip
      title={<TeamTooltipContent team={nearestTeam} />}
      placement="top"
    >
      <span>{nearestTeam.name}</span>
    </Tooltip>
  );
}
```
