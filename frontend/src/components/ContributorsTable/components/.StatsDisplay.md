Renders a horizontal row of styled stat pills for a GitHub contributor, displaying score, commits, Java repos, stars, forks, and last active date — each with an icon and formatted value.

## Key Components

**`StatsDisplay`** — `React.FC<StatsDisplayProps>`
A presentational component that maps contributor data into a list of icon + value badge pairs rendered as rounded pill-shaped MUI `Box` elements.

**Stats rendered (in order):**

| Label | Source Field | Formatting |
|---|---|---|
| Score | `contributor.score` | `formatNumber()` |
| Commits | `contributor.totalCommits` | `formatNumber()` |
| Java Repos | `contributor.javaRepos` | Raw number |
| Stars | `contributor.starsReceived` | `formatNumber()` |
| Forks | `contributor.forksReceived` | `formatNumber()` |
| Last Active | `contributor.latestCommitDate` | UTC → `en-US` locale date |

**Dependencies:**
- `formatNumber` from `../utils` — formats large numbers for display
- `githubToOds` from `../../../styles/colorMappings` — applies themed colors (`bgDark`, `textPrimary`, `textSecondary`)

## Usage Example

```typescript
import { StatsDisplay } from './StatsDisplay';

const contributor = {
  score: 9420,
  totalCommits: 1837,
  javaRepos: 12,
  starsReceived: 504,
  forksReceived: 88,
  latestCommitDate: [2024, 11, 3, 14, 22]
};

<StatsDisplay contributor={contributor} />
```

> The `latestCommitDate` field is expected as a numeric array in `[year, month, day, hour, minute]` format. The component constructs a UTC `Date` object and formats it as `M/D/YYYY` for display.
