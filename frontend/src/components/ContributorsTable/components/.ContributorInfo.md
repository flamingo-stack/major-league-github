Renders a contributor's avatar, rank badge, name, social links, and an optional "Join Team" button within a leaderboard card row.

## Key Components

- **`ContributorInfo`** – Main exported React component. Accepts a `contributor` object, a zero-based `index` for rank styling, and an optional `hiringManagerUsername` to conditionally render a "Join Team" CTA.
- **`getSocialIcon`** – Internal helper that maps a social platform name string (`'linkedin'`, `'twitter'`, `'x'`, `'github'`, `'bluesky'`, `'mastodon'`, `'email'`, `'website'`, etc.) to the appropriate MUI or custom icon element.
- **`ContributorTooltipContent`** – Imported sub-component rendered inside an MUI `Tooltip` on hover/touch, showing extended contributor details.

## Usage Example

```typescript
import { ContributorInfo } from './ContributorInfo';

// Inside a leaderboard list render:
<ContributorInfo
  contributor={{
    login: 'octocat',
    name: 'The Octocat',
    avatarUrl: 'https://github.com/octocat.png',
    url: 'https://github.com/octocat',
  }}
  index={0}                          // 0 = gold medal, 1 = silver, 2 = bronze
  hiringManagerUsername="octocat"    // shows "Join Team" button for this user
/>
```

## Rank Badge Logic

| `index` | Medal emoji | Badge color |
|---------|-------------|-------------|
| `0` | 🥇 | Gold |
| `1` | 🥈 | Silver |
| `2` | 🥉 | Bronze |
| `3+` | *(none)* | Muted secondary |

The "Join Team" button, when rendered, scrolls the page to the footer and auto-expands it via `data-testid="expand-footer"`. Tooltip styling mirrors GitHub's dark-mode panel aesthetic using `githubToOds` color tokens from `colorMappings`.
