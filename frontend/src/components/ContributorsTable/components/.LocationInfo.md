Displays a contributor's city/state and nearest MLS team with a responsive layout that adapts between mobile (inline row) and desktop (stacked column) views.

## Key Components

- **`LocationInfo`** — Main exported component that accepts a `LocationInfoProps` object containing a `contributor` record. Renders a fallback "No location provided" message when `contributor.city` is absent.
- **Nearest team section** — When `contributor.nearestTeam` is present, renders the team logo and name as a clickable external link with a `LocationTooltipContent` tooltip. Displayed inline on mobile (`xs`) and stacked below the city on desktop (`sm`+).
- **`LocationTooltipContent`** — Imported tooltip body rendered inside a styled MUI `Tooltip` with a dark themed border and shadow.

## Usage Example

```typescript
import { LocationInfo } from './LocationInfo';

const contributor = {
  city: { name: 'Seattle', state: { code: 'WA' } },
  nearestTeam: {
    name: 'Seattle Sounders FC',
    logoUrl: 'https://example.com/sounders.png',
    teamUrl: 'https://www.soundersfc.com',
  },
};

<LocationInfo contributor={contributor} />
```

**No location case:**

```typescript
// Renders "No location provided" in secondary text color
<LocationInfo contributor={{ city: null }} />
```

## Notes

- Responsive layout breakpoints use MUI `xs`/`sm` tokens: row layout on mobile, column on desktop.
- The nearest team block is intentionally rendered twice in the JSX — once visible only on `xs` (inline with city) and once visible only on `sm`+ (below city) — to handle the layout shift cleanly without CSS reflow tricks.
- Tooltip touch support is enabled via `disableTouchListener={false}` and `enterTouchDelay={0}`.
