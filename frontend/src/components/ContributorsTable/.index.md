Responsive container component for displaying GitHub contributors data. Conditionally renders either a mobile card layout or desktop table layout based on screen size, and handles loading and error states.

## Key Components

- **`ContributorsTable`** — Main exported React component that accepts `ContributorsTableProps` and orchestrates view selection and state handling
- **`MobileView`** — Rendered on small screens (`sm` breakpoint and below)
- **`TableView`** — Rendered on medium and larger screens
- **`LoadingSpinner`** — Displayed while contributor data is being fetched
- **`ErrorMessage`** — Displayed for fetch errors or when the contributors array is empty

## Usage Example

```typescript
import { ContributorsTable } from './components/ContributorsTable';

<ContributorsTable
  contributors={contributors}
  isLoading={isLoading}
  error={error}
/>
```

## Rendering Logic

| State | Output |
|---|---|
| `isLoading === true` | `<LoadingSpinner>` |
| `error` is set | `<ErrorMessage>` with error text |
| `contributors` is empty or `null` | `<ErrorMessage message="No contributors found">` |
| Mobile viewport | `<MobileView>` |
| Desktop viewport | `<TableView>` |
