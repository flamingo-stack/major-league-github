Utility function for formatting large numbers into compact, human-readable strings with K/M suffixes.

## Key Components

- **`formatNumber(num: number): string`** — Converts a number to a shortened string: millions as `1.0M`, thousands as `1.0K`, and smaller values as plain strings.

## Usage Example

```typescript
import { formatNumber } from './utils';

formatNumber(1_500_000); // "1.5M"
formatNumber(42_300);    // "42.3K"
formatNumber(999);       // "999"
```
