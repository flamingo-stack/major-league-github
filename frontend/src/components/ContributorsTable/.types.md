Shared TypeScript interface definitions for the contributors table feature, defining data shapes for soccer teams, US states, and component props used throughout the leaderboard UI.

## Key Components

| Export | Type | Description |
|--------|------|-------------|
| `SoccerTeam` | interface | Full MLS team record including location, stadium, coach, and asset URLs |
| `State` | interface | US state entity with display metadata and associated region IDs |
| `ContributorInfoProps` | interface | Props for rendering a single ranked contributor row |
| `LocationInfoProps` | interface | Props for contributor geographic location display |
| `StatsDisplayProps` | interface | Props for contributor GitHub statistics display |
| `LocationTooltipProps` | interface | Props for the location tooltip overlay |
| `ContributorTooltipProps` | interface | Props for the contributor detail tooltip overlay |
| `ContributorsTableProps` | interface | Top-level props for the full contributors table, including loading and error states |

## Usage Example

```typescript
import {
    SoccerTeam,
    State,
    ContributorsTableProps,
} from './types';

// Typing a contributors table component
const ContributorsTable: React.FC<ContributorsTableProps> = ({
    contributors,
    isLoading,
    error,
}) => {
    if (isLoading) return <LoadingSpinner />;
    if (error) return <ErrorMessage error={error} />;
    return <Table rows={contributors} />;
};

// Typing an MLS team record
const team: SoccerTeam = {
```
