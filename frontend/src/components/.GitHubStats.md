Displays a GitHub contributor's statistics panel with responsive layouts for mobile and desktop viewports, rendering metrics like score, commits, pull requests, issues, stars, forks, and last active date using Material-UI components.

## Key Components

- **`GitHubStats`** (interface) — Shape of the stats data object, including `score`, `totalCommits`, `javaRepos`, `starsReceived`, `forksReceived`, `starsGiven`, `forksGiven`, `totalPullRequests`, and `totalIssues`
- **`GitHubStatsProps`** (interface) — Props for the exported component: a `stats` object and a Unix timestamp string `lastActive`
- **`StatItem`** — Internal helper component rendering a single icon + value chip used in the compact mobile layout
- **`GitHubStats`** (component) — Main exported component; switches between a wrapped chip row (mobile) and a 4-column grid (desktop: Score, Activity, Engagement, Last Active)
- **`formatScore`** — Formats large numbers into abbreviated strings (e.g., `1200` → `1.2K`, `2500000` → `2.5M`)
- **`formatDate`** — Converts a Unix epoch string (seconds) to a human-readable date like `Jan 5, 2024`

## Usage Example

```typescript
import { GitHubStats } from './GitHubStats';

const stats = {
  score: 42500,
  totalCommits: 318,
  javaRepos: 12,
  starsReceived: 204,
  forksReceived: 47,
  starsGiven: 89,
  forksGiven: 15,
  totalPullRequests: 56,
  totalIssues: 23,
};

<GitHubStats
  stats={stats}
  lastActive="1710000000"
/>
```

The component returns `null` if `stats` is falsy, making it safe to render before data loads.
