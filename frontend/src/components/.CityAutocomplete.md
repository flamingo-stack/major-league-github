Controlled autocomplete component for searching and selecting cities, with optional filtering by region or state.

## Key Components

- **`CityAutocomplete`** — Main exported component built on top of `BaseAutocomplete<City>`, wired to the `autocompleteCities` API via React Query
- **`CityAutocompleteProps`** — Interface defining controlled input state (`value`, `inputValue`) and optional filter parameters (`regionId`, `stateId`)
- **React Query (`useQuery`)** — Fetches city suggestions keyed on `[cities, inputValue, regionId, stateId]`; always refetches on mount with no stale cache
- **`renderOptionContent`** — Renders each dropdown option with the city name and, when available, the associated state's flag icon and name

## Usage Example

```typescript
import { useState } from 'react';
import { City } from '../types/api';
import { CityAutocomplete } from './CityAutocomplete';

const LocationFilter = () => {
  const [city, setCity] = useState<City | null>(null);
  const [cityInput, setCityInput] = useState('');

  return (
    <CityAutocomplete
      value={city}
      onChange={setCity}
      inputValue={cityInput}
      onInputChange={setCityInput}
      stateId="CA" // optional: narrow results to California
    />
  );
};
```

## Notes

- `staleTime: 0` combined with `refetchOnMount: 'always'` ensures suggestions stay fresh on every render, important for search-as-you-type UX
- Both `regionId` and `stateId` are optional; omitting them returns unfiltered city suggestions
- State icons are rendered as 24×16px images with `objectFit: cover`, matching the flag-style display used elsewhere in the leaderboard UI
