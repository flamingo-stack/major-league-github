A reusable loading state component that displays a centered spinner with an optional status message, styled with the project's design token colors.

## Key Components

- **`LoadingSpinner`** — Named export; a functional component that renders a vertically centered `CircularProgress` indicator from MUI paired with a `Typography` label.
- **`LoadingSpinnerProps`** — Interface accepting a single optional `message` prop (defaults to `'Loading...'`).

## Usage Example

```typescript
// Default usage
<LoadingSpinner />

// With a custom message
<LoadingSpinner message="Fetching leaderboard data..." />
```

## Design Notes

- Spinner color uses `flamingo.cyan_light` from the shared color token system (`../styles/colors`) rather than a hardcoded hex value.
- Message text uses `systemGreys.grey_hover` for consistent contrast against both light and dark backgrounds.
- The container enforces `minHeight: '200px'` and `width: '100%'` so the spinner occupies a predictable space without causing layout shift.
