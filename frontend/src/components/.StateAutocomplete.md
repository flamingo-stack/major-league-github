A controlled autocomplete component for searching and selecting U.S. states, built on top of `BaseAutocomplete` with state-specific rendering including flag icons.

## Key Components

- **`StateAutocompleteProps`** — Interface defining `value`, `onChange`, `inputValue`, `onInputChange`, and optional `regionId` filter
- **`useQuery`** — Fetches matching states from the API via `autocompleteStates`, keyed on `inputValue` and `regionId`; always refetches on mount
- **`BaseAutocomplete<State>`** — Generic autocomplete shell that receives state-specific option rendering
- **Option rendering** — Displays a flag/icon thumbnail (`24×16px`) alongside the state name

## Usage Example

```typescript
import { useState } from 'react';
import { StateAutocomplete } from './StateAutocomplete';
import { State } from '../types/api';

const FilterPanel = () => {
  const [selectedState, setSelectedState] = useState<State | null>(null);
  const [inputValue, setInputValue] = useState('');

  return (
    <StateAutocomplete
      value={selectedState}
      onChange={setSelectedState}
      inputValue={inputValue}
      onInputChange={setInputValue}
      regionId="northeast" // optional: narrows results to a region
    />
  );
};
```

## Notes

- `staleTime: 0` and `refetchOnMount: 'always'` ensure results stay fresh as the user types
- The `regionId` prop optionally scopes results to a geographic region, useful when a region filter is already applied upstream
- Icon images use `objectFit: 'cover'` and a slight border radius for a flag-thumbnail appearance
- Passes an `AbortSignal` to `autocompleteStates` to cancel in-flight requests when the query key changes
