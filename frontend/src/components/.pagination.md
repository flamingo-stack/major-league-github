A minimal React pagination component for Major League GitHub that renders Previous/Next navigation controls, hiding itself entirely when only one page exists.

## Key Components

### `PaginationProps`
| Prop | Type | Description |
|------|------|-------------|
| `currentPage` | `number` | The currently active page (1-based) |
| `totalPages` | `number` | Total number of available pages |
| `onPageChange` | `(page: number) => void` | Optional callback invoked when the user navigates |

### `Pagination`
The default named export. Renders a centered row with **Previous** and **Next** buttons flanking a `Page X of Y` label. Both buttons clamp navigation within bounds — Previous floors at `1`, Next caps at `totalPages`. Returns `null` when `totalPages <= 1`, so callers never need to conditionally render it themselves.

## Usage Example

```typescript
import { Pagination } from './pagination';

function LeaderboardFooter() {
  const [page, setPage] = React.useState(1);
  const totalPages = 8;

  return (
    <>
      <LeaderboardTable page={page} />
      <Pagination
        currentPage={page}
        totalPages={totalPages}
        onPageChange={setPage}
      />
    </>
  );
}
```

> **Note:** This is a lightweight stub introduced to satisfy `ui-kit` persistent-pagination imports. It intentionally avoids complex patterns (page-number lists, jump-to-page inputs, etc.) not needed by Major League GitHub. If richer pagination is required in the future, see [`flamingo-stack/major-league-github`](https://github.com/flamingo-stack/major-league-github) for the full project context.
