Renders a compact soccer team display combining a square logo avatar with the team name, used for showing MLS team affiliations in the leaderboard UI.

## Key Components

- **`SoccerTeamDisplay`** — Exported functional component that accepts a `SoccerTeam` object and renders a 24×24px square logo alongside the team name.
- **`SoccerTeamDisplayProps`** — Interface requiring a single `team` prop of type `SoccerTeam` (sourced from `../types/api`).

## Usage Example

```typescript
import { SoccerTeamDisplay } from './components/SoccerTeamDisplay';
import { SoccerTeam } from './types/api';

const team: SoccerTeam = {
  name: 'LA Galaxy',
  logoUrl: 'https://example.com/logos/la-galaxy.png',
};

<SoccerTeamDisplay team={team} />
```

## Notes

- The avatar uses `variant="square"` with `objectFit: contain` to preserve logo aspect ratios without cropping.
- Background is transparent (`bgcolor: 'transparent'`) so logos with transparent PNGs render cleanly against any surface.
- Team name renders as `body2` in `text.secondary` color, keeping it visually subordinate to primary leaderboard content.
