The `HeroSection` component renders the top banner of the Major League GitHub web app, displaying the project title, a description, and call-to-action buttons linking to the blog post and GitHub repository.

## Key Components

| Export | Type | Description |
|---|---|---|
| `HeroSection` | `React.FC` | Main hero banner component |
| `StyledTitle` | MUI styled component | Monospaced "Azeret Mono" title with responsive sizing |
| `StyledDescription` | MUI styled component | "DM Sans" body text, max-width constrained |
| `ExternalLinkIcon` | Function component | Inline SVG arrow icon for external links |
| `GITHUB_LINK` | `string` | Hardcoded URL to the GitHub repository |
| `BLOG_LINK` | `string` | Env-configurable URL (`WEBAPP_EXTRA_BUTTON_LINK`) with fallback to the MLG blog post |
| `BLOG_TEXT` | `string` | Env-configurable CTA label (`WEBAPP_EXTRA_BUTTON_TEXT`), defaults to `"Why MLG?"` |

**Layout behavior:**
- On mobile (`xs`): stacked column layout with the `MlgLogo` rendered above the title text
- On desktop (`lg`+): side-by-side layout with a larger `MlgLogo` on the right

## Usage Example

```typescript
import { HeroSection } from './components/HeroSection';

// Renders in app root or page layout:
export default function App() {
  return (
    <>
      <HeroSection />
      {/* rest of page */}
    </>
  );
}
```

**Optional environment variable overrides** (set before build):

```bash
WEBAPP_EXTRA_BUTTON_LINK=https://your-custom-link.example.com
WEBAPP_EXTRA_BUTTON_TEXT=Learn More
```

If unset, the button defaults to the [Flamingo blog post about MLG](https://www.flamingo.run/blog/major-league-github-the-open-source-talent-leaderboard) with the label `"Why MLG?"`.
