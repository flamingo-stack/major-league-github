Reusable error message banner component that displays a styled alert box with an icon and descriptive text, using the application's ODS-based error color tokens.

## Key Components

- **`ErrorMessage`** — A functional React component that renders a Material-UI `Paper` container styled as an error alert, combining `ErrorOutlineIcon` with a typography message.
- **`ErrorMessageProps`** — Interface accepting a single `message: string` prop for the displayed error text.
- **`attention` colors** — Pulls `red_error` and `red_error_hover` tokens from the shared color palette for consistent error styling across the app.

## Usage Example

```typescript
import { ErrorMessage } from './components/ErrorMessage';

// Display a generic fetch error
<ErrorMessage message="Failed to load leaderboard data. Please try again." />

// Display a location error
<ErrorMessage message="Unable to determine your current location." />
```

## Notes

- The background uses `red_error` at **15% opacity** (`26` hex) and the border at **40% opacity** (`66` hex), keeping the alert visually soft rather than alarming.
- The message text uses `red_error_hover` (a darker shade) to ensure sufficient contrast against the light red background.
- The component stretches to full container width (`width: '100%'`) and is suitable for placement inside any layout column or card.
