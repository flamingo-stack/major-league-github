A React component that wraps the MLG application logo SVG as a Material-UI `SvgIcon`, enabling full MUI icon integration including prop forwarding and ref support.

## Key Components

- **`Logo`** – A `forwardRef` component that renders `logo.svg` via MUI's `SvgIcon`, inheriting the SVG's native `viewBox` and accepting all standard `SvgIconProps` (e.g., `fontSize`, `color`, `sx`).

## Usage Example

```typescript
import { Logo } from './components/Logo';

// Basic usage
<Logo />

// With MUI icon props
<Logo fontSize="large" color="primary" sx={{ mr: 1 }} />

// With a forwarded ref
const ref = React.useRef<SVGSVGElement>(null);
<Logo ref={ref} />
```
