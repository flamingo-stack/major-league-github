Sticky site header component rendered at the top of every page, containing the app logo, title, and navigation links.

## Key Components

- **`Header`** — Default export. A sticky MUI `Box` that renders the top navigation bar with three sections: a home link (logo + title), an optional blog/extra button, and a GitHub repository icon link.
- **`BLOG_LINK`** — Configurable via `WEBAPP_EXTRA_BUTTON_LINK` env var; defaults to the MLG blog post URL.
- **`BLOG_TEXT`** — Configurable via `WEBAPP_EXTRA_BUTTON_TEXT` env var; defaults to `"Why MLG?"`.

## Key Behaviors

- Stays fixed at the top of the viewport (`position: sticky`, `zIndex: 1000`).
- The blog button is hidden on viewports narrower than 450 px; the GitHub icon link is hidden below 420 px.
- Both external links (`BLOG_LINK` and the GitHub repo) open in a new tab with `noopener noreferrer`.
- Hover states transition link borders and text to `flamingo.cyan_base`.

## Usage Example

```typescript
// Rendered once at the app root — no props required
import Header from './components/Header';

function App() {
  return (
    <>
      <Header />
      {/* page content */}
    </>
  );
}
```

To override the blog button at runtime:

```bash
WEBAPP_EXTRA_BUTTON_LINK=https://example.com/about \
WEBAPP_EXTRA_BUTTON_TEXT="About MLG" \
npm run dev
```
