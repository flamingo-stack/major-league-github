Renders the filter controls panel for the Major League GitHub leaderboard, allowing users to filter contributors by programming language, MLS team, region, state, and city, with URL-synchronized state and CSV export functionality.

## Key Components

- **`FiltersPanel`** — Primary exported component that renders the full filter UI with responsive layout (mobile/desktop), URL state hydration, and export controls
- **`dismissKeyboard`** — Utility that blurs the active element to hide the soft keyboard on mobile after autocomplete selection
- Filter state handlers: **`handleLanguageChange`**, **`handleTeamChange`**, **`handleRegionChange`**, **`handleStateChange`**, **`handleCityChange`** — each updates local state and syncs to URL params, clearing dependent filters (e.g., clearing city when region changes)
- **`handleExportClick`** / **`handleExportSize`** — Trigger CSV download via `downloadContributors`, optionally prompting for a result-size selection via a `Dialog`

## Usage Example

```typescript
// Drop into any page layout — no props required; reads/writes URL state internally
import { FiltersPanel } from './components/FiltersPanel';

function LeaderboardPage() {
  return (
    <Box>
      <FiltersPanel />
      {/* Leaderboard table below reads the same URL state */}
    </Box>
  );
}
```

## Behavior Notes

- **Default language**: Java is automatically resolved and set on first load if no `languageId` is present in the URL
- **Keyboard shortcut**: `Option+E` (Mac) or `Alt+E` (Windows/Linux) opens the export size-selection dialog
- **Responsive layout**: `TeamAutocomplete`, region/state/city filters, and the "Download CSV" link are hidden on mobile (`xs`); a collapsible `Collapse` section exposes additional filters on small screens
- **Error recovery**: If any entity lookup fails during URL hydration, only the offending ID is cleared from URL state; other filters are preserved
