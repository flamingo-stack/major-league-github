A controlled autocomplete component for searching and selecting geographic regions, with support for filtering by state or city and rendering associated state icons inline.

## Key Components

- **`RegionAutocompleteProps`** — Interface defining the component's inputs:
  - `value` / `onChange` — Controlled selected `Region` value
  - `inputValue` / `onInputChange` — Controlled text input state
  - `stateId` — Optional filter to scope results to a specific state
  - `cityIds` — Optional filter to scope results to specific cities

- **`useQuery`** — Fetches region suggestions via `autocompleteRegions` whenever `inputValue`, `stateId`, or `cityIds` change; always refetches on mount with `staleTime: 0`

- **`BaseAutocomplete<Region>`** — Generic autocomplete shell that handles rendering, keyboard navigation, and option selection

- **Option renderer** — Displays the region's `displayName` as a bold heading, followed by a horizontally wrapped list of associated states, each showing a 20×20 flag/icon and the state name

## Usage Example

```typescript
import { RegionAutocomplete } from './RegionAutocomplete';
import { Region } from '../types/api';
import { useState } from 'react';

const MyFilter = () => {
  const [region, setRegion] = useState<Region | null>(null);
  const [input, setInput] = useState('');

  return (
    <RegionAutocomplete
      value={region}
      onChange={setRegion}
      inputValue={input}
      onInputChange={setInput}
      stateId="CA"           // optional: narrow results to California
      cityIds={['LA', 'SF']} // optional: narrow results to specific cities
    />
  );
};
```
