A controlled autocomplete component for searching and selecting programming languages, backed by a live API query that refreshes on every input change.

## Key Components

| Name | Type | Description |
|---|---|---|
| `LanguageAutocomplete` | Component | Main export; wraps `BaseAutocomplete` with language-specific query logic |
| `LanguageAutocompleteProps` | Interface | Props for controlled value, input state, change handlers, and optional MUI `sx` styling |
| `useQuery` | Hook (internal) | Fetches language suggestions via `autocompleteLanguages` keyed on `['languages', inputValue]` with `staleTime: 0` to always refetch |

## Usage Example

```typescript
import { useState } from 'react';
import { Language } from '../types/api';
import { LanguageAutocomplete } from './LanguageAutocomplete';

const FilterPanel = () => {
  const [language, setLanguage] = useState<Language | null>(null);
  const [inputValue, setInputValue] = useState('');

  return (
    <LanguageAutocomplete
      value={language}
      onChange={setLanguage}
      inputValue={inputValue}
      onInputChange={setInputValue}
      sx={{ width: 300 }}
    />
  );
};
```

## Notes

- `staleTime: 0` ensures suggestions are always fetched fresh on each keystroke — appropriate for a search-as-you-type experience.
- The `AbortSignal` from React Query is forwarded to `autocompleteLanguages`, cancelling in-flight requests when the query key changes.
- Display text is derived from `Language.displayName` via `getOptionLabel`.
