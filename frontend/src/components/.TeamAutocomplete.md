A controlled autocomplete input for searching and selecting MLS soccer teams, built on top of `BaseAutocomplete` with team-specific rendering including logos and location details.

## Key Components

### `TeamAutocompleteProps`
| Prop | Type | Description |
|---|---|---|
| `value` | `SoccerTeam \| null` | Currently selected team |
| `onChange` | `(team: SoccerTeam \| null) => void` | Callback when selection changes |
| `inputValue` | `string` | Controlled text input value |
| `onInputChange` | `(value: string) => void` | Callback when input text changes |
| `sx` | `SxProps<Theme>` | Optional MUI style overrides |

### `TeamAutocomplete`
Queries `autocompleteTeams` via React Query on each `inputValue` change (`staleTime: 0`, `refetchOnMount: 'always'`) to ensure fresh results. Renders each option as a two-line row: team logo + name on the first line, city and state on the second.

## Usage Example

```typescript
const [team, setTeam] = useState<SoccerTeam | null>(null);
const [inputValue, setInputValue] = useState('');

<TeamAutocomplete
  value={team}
  onChange={setTeam}
  inputValue={inputValue}
  onInputChange={setInputValue}
  sx={{ width: 300 }}
/>
```

## Notes

- Results are fetched on every keystroke with no caching (`staleTime: 0`) to keep suggestions current.
- Passes an `AbortSignal` to `autocompleteTeams` so in-flight requests are cancelled when the query key changes.
- Option display falls back gracefully when `logoUrl` is absent — the image element is conditionally rendered.
