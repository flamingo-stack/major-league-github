Webpack configuration for the Major League GitHub React frontend, defining build pipeline, dev server, asset handling, and environment variable injection for both development and production modes.

## Key Components

| Plugin / Loader | Purpose |
|---|---|
| `HtmlWebpackPlugin` | Injects environment variables (OG tags, GTM ID, API URL) into `index.html` |
| `SeoFilesPlugin` | Generates `sitemap.xml` and `robots.txt` at build time |
| `FaviconGeneratorPlugin` | Converts `public/favicon.svg` to a multi-size `.ico` |
| `CopyWebpackPlugin` | Copies static assets from `public/` to `dist/`, excluding generated files |
| `webpack.DefinePlugin` | Exposes `process.env` to client-side code |
| `TerserPlugin` | Minifies JavaScript in production builds |
| `ts-loader` | Transpiles TypeScript/TSX with `transpileOnly: true` for speed |
| `@svgr/webpack` | Imports SVGs as React components when used from JS/TS files |

## Environment Variables

| Variable | Default | Description |
|---|---|---|
| `PORT` | `8450` | Dev server port |
| `BACKEND_API_URL` | `https://www.mlg.soccer` | API proxy target |
| `NODE_ENV` | `development` | Build mode |
| `OG_URL` / `BASE_URL` | `https://www.mlg.soccer` | Canonical URL for SEO files |

## Usage Example

```bash
# Development server (proxies /api to BACKEND_API_URL)
NODE_ENV=development BACKEND_API_URL=http://localhost:8450 npx webpack serve

# Production build
NODE_ENV=production npx webpack --mode production
```

**Path aliases** available in source code:

```typescript
import MyComponent from '@/components/MyComponent'; // → src/
import { Button } from '@flamingo/ui-kit';          // → ui-kit/src/
```

**Dev server** runs on `localhost:8450` by default, proxying all `/api` requests to `BACKEND_API_URL` with `changeOrigin: true`. Source maps are enabled in development only; chunks are split automatically in both modes.
