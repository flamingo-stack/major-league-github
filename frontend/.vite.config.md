Vite build configuration for the Major League GitHub React frontend, enabling React Fast Refresh and SVG-as-React-component support.

## Key Components

| Export | Description |
|---|---|
| `default` (defineConfig) | Vite config with React and SVGR plugins |

**Plugins:**
- **`@vitejs/plugin-react`** — Babel-based React support with Fast Refresh during development
- **`vite-plugin-svgr`** — Transforms `.svg` files into importable React components

## Usage Example

```typescript
// Import an SVG as a React component (enabled by vite-plugin-svgr)
import { ReactComponent as Logo } from './assets/logo.svg';

function App() {
  return <Logo />;
}
```

```bash
# Start the dev server
npm run dev

# Production build
npm run build
```

## Notes

- No custom `server.port` or `proxy` is set here; environment-specific API routing is handled separately.
- To extend (e.g., add a dev proxy to the backend on port `8450`), update this file:

```typescript
export default defineConfig({
  plugins: [react(), svgr()],
  server: {
    proxy: {
      '/api': 'http://localhost:8450',
    },
  },
});
```
