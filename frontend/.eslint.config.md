ESLint flat-config file for the Major League GitHub frontend, wiring together TypeScript, React Hooks, and React Refresh linting rules for all `.ts` and `.tsx` source files.

## Key Components

| Export / Setting | Purpose |
|---|---|
| `ignores: ['dist']` | Excludes the production build output directory from linting |
| `js.configs.recommended` | Applies ESLint's core recommended ruleset |
| `tseslint.configs.recommended` | Applies TypeScript-ESLint recommended rules |
| `reactHooks.configs.recommended.rules` | Enforces Rules of Hooks and exhaustive-deps |
| `react-refresh/only-export-components` | Warns when non-component values are exported, keeping HMR reliable |
| `globals.browser` | Injects browser globals (e.g. `window`, `document`) into the type environment |

## Usage Example

```bash
# Run ESLint across the frontend source
npx eslint .

# Auto-fix where possible
npx eslint . --fix
```

The config is consumed automatically by ESLint 9+ via the flat-config convention — no `.eslintrc` file is needed. To extend it, add additional rule objects inside the `tseslint.config(...)` call:

```javascript
// eslint.config.js — adding a custom rule
export default tseslint.config(
  { ignores: ['dist'] },
  {
    // ...existing config...
    rules: {
      ...reactHooks.configs.recommended.rules,
      'react-refresh/only-export-components': ['warn', { allowConstantExport: true }],
      'no-console': 'warn', // custom addition
    },
  },
)
```
