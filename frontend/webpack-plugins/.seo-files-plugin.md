A custom Webpack plugin that generates `sitemap.xml` and `robots.txt` during the build process, injecting them directly into the compilation output.

## Key Components

- **`SeoFilesPlugin` class** — Webpack-compatible plugin with `apply(compiler)` hook integration
- **`constructor(options)`** — Accepts a `baseUrl` option (defaults to `https://www.mlg.soccer`)
- **`apply(compiler)`** — Taps into the `emit` async hook to inject SEO files into compilation assets before output is written
- **`sitemap.xml`** — Generated with the current date as `lastmod`, `daily` change frequency, and priority `1.0` for the root URL
- **`robots.txt`** — Allows all crawlers on `/`, disallows `/api/`, and references the generated sitemap

## Usage Example

```javascript
// webpack.config.js
const SeoFilesPlugin = require('./seo-files-plugin');

module.exports = {
  // ...
  plugins: [
    new SeoFilesPlugin({
      baseUrl: 'https://www.mlg.soccer'
    })
  ]
};
```

After a build, `sitemap.xml` and `robots.txt` will appear in the output directory alongside the bundled assets — no manual file management required.

> **Note:** The sitemap currently includes only the root URL (`/`). If additional routes are added to the frontend, extend the `<urlset>` block inside the `sitemapContent` string to include them.
