A custom Webpack plugin that automatically generates a `favicon.ico` file from an SVG source during the build process, with smart caching to skip regeneration when the ICO is already up to date.

## Key Components

- **`FaviconGeneratorPlugin` (class)** — Main plugin class that integrates with Webpack's compiler lifecycle.
- **`constructor(options)`** — Accepts configuration for SVG input path, ICO output path, and raster size (default: 60×60px).
- **`apply(compiler)`** — Registers the favicon generation on both `beforeRun` (production builds) and `watchRun` (development) hooks.
- **`generateFavicon(context)`** — Core conversion logic: resolves paths, checks staleness, converts SVG → PNG via `sharp`, then PNG → ICO via `to-ico`, and writes the result to disk.

## Usage Example

```javascript
// webpack.config.js
const FaviconGeneratorPlugin = require('./favicon-generator-plugin');

module.exports = {
  plugins: [
    new FaviconGeneratorPlugin({
      svgPath: 'public/favicon.svg', // input SVG (default)
      icoPath: 'public/favicon.ico', // output ICO (default)
      size: 60,                       // raster dimensions in px (default)
    }),
  ],
};
```

**Dependencies:** [`sharp`](https://sharp.pixelplumbing.com/) (SVG-to-PNG rasterization) and [`to-ico`](https://www.npmjs.com/package/to-ico) (PNG-to-ICO conversion) must be installed.

```bash
npm install sharp to-ico
```

**Caching behavior:** If `favicon.ico` already exists and is newer than `favicon.svg`, conversion is skipped, keeping incremental builds fast.
