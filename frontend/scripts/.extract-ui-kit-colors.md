A Node.js build script that extracts color tokens from a UI kit's JSON token file and CSS custom properties, then generates a typed TypeScript color module (`colors.ts`) for use in the frontend.

## Key Components

- **`extractColorsFromJSON()`** — Recursively traverses `ods_color_tokens.json`, collecting all entries with `type === 'color'`, and flattens them into a key/value map using underscore-joined paths as identifiers.
- **`extractSemanticColorsFromCSS()`** — Parses `ods-colors.css` with a regex to capture `--color-*` custom properties, keeping only direct hex values (skipping `var()` references).
- **`generateColorsFile()`** — Orchestrates extraction, creates the output directory if needed, and writes a fully-typed TypeScript file exporting `baseColors`, `semanticColors`, a merged `colors` object, a `ColorKey` type, a `getColor()` helper, and pre-grouped category exports (`attention`, `flamingo`, `openYellow`, `systemGreys`).

## Usage Example

Run directly from the command line as part of a build or codegen step:

```bash
node scripts/extract-ui-kit-colors.js
```

Or require it programmatically:

```javascript
const { generateColorsFile } = require('./scripts/extract-ui-kit-colors');

const result = generateColorsFile();
// result.baseColors     → { attention_green_success: '#...', ... }
// result.semanticColors → { primary: '#...', ... }
// result.totalColors    → 84
```

The generated `src/styles/colors.ts` can then be imported anywhere in the frontend:

```typescript
import { flamingo, getColor, type ColorKey } from './styles/colors';

const brand = flamingo.cyan_base;          // '#...'
const error = getColor('attention_red_error'); // '#...'
```

> **Note:** This script reads from `ui-kit/src/styles/` relative to the `scripts/` directory. Re-run it whenever the upstream UI kit color tokens change.
