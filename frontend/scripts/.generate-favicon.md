Converts `public/favicon.svg` to a `public/favicon.ico` file using a two-step pipeline: SVG → 60×60 PNG (via `sharp`), then PNG → ICO (via `to-ico`).

## Key Components

| Export / Function | Description |
|---|---|
| `generateFavicon()` | Async entry-point that orchestrates the SVG → PNG → ICO conversion and writes the output file |

## Usage Example

Run directly with Node.js from the project root:

```bash
node scripts/generate-favicon.js
```

Expected output:

```text
Converting SVG to ICO favicon...
Converting SVG to PNG at 60x60...
Converting PNG to ICO format...
✅ Successfully generated favicon.ico at: .../public/favicon.ico
File size: 3.78 KB
```

The script exits with code `1` if the source SVG is missing or any conversion step fails.

## Dependencies

| Package | Role |
|---|---|
| [`sharp`](https://sharp.pixelplumbing.com/) | Rasterizes the SVG to a 60×60 PNG buffer |
| [`to-ico`](https://github.com/kevva/to-ico) | Wraps the PNG buffer into the ICO container format |

## Notes

- Input: `public/favicon.svg` (must exist before running)
- Output: `public/favicon.ico` (overwritten on each run)
- Fixed output size: **60×60 px** — adjust the `.resize()` call if additional ICO sizes are needed
- Source: [`scripts/generate-favicon.js`](https://github.com/flamingo-stack/major-league-github/blob/main/scripts/generate-favicon.js)
